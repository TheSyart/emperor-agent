# 更新日志

本文件记录 Emperor Agent 的用户可感知变化，格式参考 [Keep a Changelog](https://keepachangelog.com/zh-CN/1.1.0/)。当前项目尚未在这里固定公开版本段；待版本正式发布时，再把 `Unreleased` 内容移动到带日期的版本标题下。

## [Unreleased]

### Changed

- 界面换上新的配色：深色主题从偏蓝的灰改为暖中性灰，浅色主题有了层次（暖白画布、白色面板），金色只留给发送、链接、焦点和选中的开关；状态色、细线与阴影重新调过，说明文字在浅色下更清楚；中英文之间自动留出间距。启动时窗口底色与主题一致，不再先闪一下棕色。
- 删除会话可以撤销：删除后的提示条带「撤销」（10 秒），会话原样回来；删除的会话进入「设置 › 常规 › 最近删除」保留 30 天，可以恢复或永久删除（需要确认），到期自动清除。关闭还有程序在运行的终端标签时先确认。
- 删除、清空、丢弃修改、推送、合并、断开连接、停止工作流等操作改用 Emperor 自己的确认框，不再弹系统对话框：标题说明要做什么，按钮写明动作；破坏性操作的确认按钮是红色，默认焦点在「取消」上，回车不会误删。
- 提示改为队列：最多同时显示 3 条，其余依次出现，普通提示 4 秒后消失，重复的提示不再叠加。出错的提示会一直留着，直到你关闭，并提供「复制详情」（含错误 ID，可与日志对照）。
- 弹窗打开时焦点进入弹窗，Tab 不会跑到背后的页面，背后的内容不可点击；关闭后焦点回到打开它的按钮。设置面板、图片预览和首启的「配置模型」弹窗都一样，嵌套弹窗按 Esc 只关最上面一层。
- 状态标签、圆点、头像、提示条、空状态、输入框、搜索框、勾选框和页签换成统一的一套：输入框与下拉框同为 32px 高、细线描边，聚焦时显示金色焦点环；正在运行的状态改为金色呼吸点，审批和计划用橙色点；各处的搜索框都能用 Esc 清空、用 × 清除；子智能体头像按显示尺寸裁剪，列表里滚动更省内存。

- Claude Code 与 Codex 子智能体默认关闭：它们使用你自己的订阅额度或 API 计费，需要在「设置 › 子智能体」打开。第一次把任务交给某个执行器时，对话里会弹出确认卡（本次允许 / 以后都允许 / 不允许），选「不允许」时任务改由本地子智能体完成。升级前没有改过这项设置的，外部执行器会被关闭，设置页会说明一次。
- 没有启用外部执行器时，主模型不再收到任何外部执行器说明；启用时说明大幅缩短，也不再鼓励主模型不经你同意直接派工。本地子智能体的工具说明恢复原样，给子智能体的后续消息按原文送达，不再加「Task:」标题。Plan 模式下允许只读的子智能体审查。

- Claude Code 子智能体默认使用随 Emperor 发布的 Claude Code，本机 claude 自动更新后不再被判为「版本不兼容」；设置里可改用本机安装的 claude（需要 2.1 或更高）。Codex 不再要求精确的 0.153.4：同一次版本（0.153.x）都可用，协议有变化时提示「可能不兼容」但仍可运行，其他版本会显示需要的版本范围。旧配置里的固定版本号会被自动清除。
- 切换模型或备用模型接手时，Agent 会在对话里收到一条“本步起由 X 模型继续”的说明；系统提示词不再写当前模型和工作目录（改由运行时上下文给出），切换模型因此不会改写提示词开头、白白失去前缀缓存。升级后已有会话的下一次请求会重新建立一次缓存。
- Plan 审阅点“取消”后本轮立即结束，等你输入自己的意见，不再为“等待用户”多请求一次模型。
- `bash` 工具要求模型先写一句命令用途再写命令，删除或移动文件前先核对解析后的绝对路径，路径里的变量写成 `${VAR:?}`。

- 子智能体使用 36 个生成角色头像，逐个校正居中、耳朵／天线留白及相邻图像残留；文件图标采用审核后的彩色候选，正文与侧栏一致。

- 文件名和附件内容统一进入右侧文件面板，普通聊天与草稿也可预览；图片使用全窗口灯箱，支持缩放、拖动、旋转与同组切换。「查看变更」继续独立显示差异。
- 发送前后的图片附件仅显示缩略图，去掉文件名、大小和类型文字；输入框保留移除按钮，图片文件仍可从灯箱进入文件面板。

- 本轮文件改动卡采用分层标题、独立增删统计与文件类型图标，默认三行，长路径完整换行，支持「查看变更」与撤销确认。

- 网站链接采用更舒展的图标与名称排版：修复 favicon 与文字贴合，移除常态标签底色，增加相邻链接、来源清单与资源卡片的留白。

- 对话行内链接移除逐条省略号详情按钮，长资源标题与来源名称改为完整换行显示；详情保留在卡片和来源／输出清单。子智能体新增稳定分配的角色头像，侧栏与委派记录使用同一形象。

- 本轮未签名 Preview 只发布 macOS arm64 / x64 的 DMG 与 ZIP；发布清单、回执和来源校验按双架构完整验证，Windows / Linux 暂不更新。

### Fixed

- 新建构建项目时在选择文件夹窗口点「取消」不再弹出报错。
- 侧栏归档、重命名失败不再悄无声息：会弹出原因，归档失败时不取消置顶、不跳转；「已归档对话」读取失败时显示错误和「重试」，不再显示成「暂无归档对话」。
- 在还没发过消息的新对话里直接启动 Goal 不再报 `unknown session`：Goal 落在新建出的会话里；启动期间切到别的会话，Goal 也留在发起它的会话。
- 「设置 › 电脑操作」的总开关随时可用：「重新连接」或请求系统权限还在等待时，也能立即关闭电脑操作。页面上的这些操作超过 30 秒没有完成就停止等待并说明原因，页面不再一直灰着。
- 侧栏布局没读取成功时，置顶、排序和折叠不会再用默认布局覆盖你保存的设置，而是提示稍后再试并重新读取。
- 用户消息只有真正进入对话才算发出：压缩等准备步骤期间点停止、成本上限或 Hook 拦下这一步时，消息回到队首，不再丢失；一轮出错后排在后面的消息不再被悄悄搁置，提交也不再报告「完成」，而是留在队列里显示「待发送 · 上一轮失败」，可以「发送」或「丢弃」。
- 停止后排队的消息保留为「待发送 · 上一轮已停止」，不再被清除，也不会自动接着运行；应用在消息发出前退出或崩溃时，重新打开会话后它显示为「待发送 · 应用重启前未发出」。
- ACP 的 `session/cancel` 与定时任务取消只作用于自己的消息：还在排队时把它移出队列，正在运行的其他 turn 不受影响；排在失败 turn 后面的 ACP prompt 返回 `refusal` 并从队列撤回，定时任务记为失败。
- 子智能体（Claude Code / Codex）在 Emperor 退出、崩溃或电脑重启后不再长期卡在「结果待确认」：下次启动直接显示「已中断」，释放并发名额，Goal 不再被它挡住；无法确认已停下的任务在环境信息卡、子智能体对话页和任务详情里有「标记为已结束」按钮，父 Agent 也可以请求标记（需要你同意）。停止子智能体最多约 10 秒（中断、5 秒后结束整组进程、再 5 秒强制结束）；运行时不再每秒十次查询进程列表，中文系统下也能正确识别进程，不会因为进程号被复用而误停别的程序。启动时不再给所有历史子任务写记录、也不再打开旧会话执行它们的启动 hook，原有的失败原因不再被改写；`/private/tmp` 里超过一天的 `emperor-boundary-*` 文件会被清理。离开进程组的进程不再默认追踪，需要时在「设置 › 子智能体 › 高级」打开诊断模式。
- 再次打开已在运行的 Emperor 只会把它的窗口带到前台；数据目录被另一个 Emperor 占用时，恢复页写明对方的版本和 pid，并可一键切换过去；恢复页「重试」不再重复创建电脑操作驱动或卡在重复注册上。
- 退出时先写完会话记录；关闭卡住超过 5 秒时强制结束子进程和终端后退出，不再残留后台进程。
- 从浏览器导入密码不再冻结界面：等待钥匙串授权时应用仍可操作（一分钟无响应即放弃），一千条密码只写一次磁盘。
- 凭据库文件 `vault.json` 损坏或由更新版本的 Emperor 写入时，应用照常启动，只是暂时不能代填账号密码；原文件保持不变。「设置 › 浏览器 › 密码管理器」写明「凭据库无法读取」（或「由更新版本的 Emperor 写入」，只列名称），可以「从备份恢复」，或「重新开始（先备份）」：原文件另存为 `vault.json.unreadable-<时间>`／`.newer-<时间>` 后从空的凭据库开始。
- 本地密钥文件被 `chmod -R 700` 之类收紧权限后照常可用；只有其他用户也能读取时才停用，并先提供「修复权限」（恢复为只有你能读写），不再只剩删光全部密码的「清空」。新建本地密钥后会同步目录，断电后不会丢失。
- 解锁凭据库不再让界面卡住半秒：主密码的 scrypt 派生改在后台线程进行。
- 桌宠开着时关掉主窗口，点 Dock 图标或桌宠右键「打开主窗口」都能重新打开；连按刷新不再被当作加载失败退出；拔掉外接显示器后窗口与桌宠回到可见的屏幕上。
- 临时浏览任务复用最多 4 个清空过的会话分区，不再每个任务留下一个无法释放的会话；电脑操作 Helper 的 socket 跟随自定义 `EMPEROR_CONFIG_DIR`。

- `memory_edit` 原样写入替换文本（`$&`、`$'`、`$$` 不再被展开，避免把文件其余内容复制进记忆）；疑似密钥和提示词注入内容拒绝写入；非 `danger-full-access` 下每个会话第一次写记忆前请你批准。
- 审批回答没有选项 id 时一律按拒绝处理，「不允许」不再被当成允许。
- 定时任务运行中不能再修改、恢复、立即运行或删除任何定时任务。

- 输入框不再丢草稿：发送被拒绝时原文、芯片和附件都会放回；每个会话保留自己的草稿；切换会话的瞬间回车不会发到上一个会话；附件上传完前不能发送，同名文件互不干扰；可以直接粘贴截图；编辑排队消息会带回附件，且不覆盖已输入的内容。
- 不是命令的 `/词`（如 `/tmp 下有什么`）会提示后作为普通消息发送，不再被当成未知命令丢掉。
- 审批、提问和计划卡片上按 Esc 只收起卡片，不再直接取消；输入法组字时的 Esc 不受影响。
- 发送前检测消息里疑似的 API Key、令牌和私钥，可选择遮掩后发送。
- Codex 子智能体不再复制你的 Codex 登录令牌：子任务与你自己的 Codex 共用 `~/.codex/auth.json`，子任务刷新登录后你自己的 Codex 不会被登出；同一时间只有一个 Codex 子任务可能刷新登录，其余排队。旧版本留下的令牌副本在下次运行前处理掉，设置页检测登录不再每次生成新的带令牌目录。Codex 一律使用文件保存登录，不使用钥匙串。
- Codex 子智能体提问后几分钟才回答、或运行长时间没有输出的命令时，不再被 2 分钟空闲计时停止；只有超过运行上限（默认 30 分钟）才停止，并注明是超时。多轮大输出后的 Codex 会话可以继续派工，恢复会话不再一次拉取全部历史。
- Codex 使用 Azure 等自定义提供方时保留 `query_params`（如 `api-version`）；从程序坞启动 Emperor 时也能读到 `~/.zshrc` 中导出的提供方密钥。

- 应用在压缩上下文、运行工作流、后台任务或子代理途中崩溃后，重新打开会话会把它们标成「已中断」：不再一直显示运行中，`/compact` 也不再永远提示正在压缩。

- 写会话记录时断电、强退或磁盘写满，不再让会话永久打不开：末尾的半行在下次打开时移出另存，中间损坏的行之前的内容会保留，原文件另存备份；回合结束、提问和审批会立即写入磁盘，退出时先写完所有会话再关闭，关闭卡住超过 5 秒也照样退出。
- 一步内部出错（例如工具结果无法写入会话记录）后，会话可以继续：留下的工具调用会补上“结果未知”或“未开始”的结果，严格校验调用与结果配对的模型服务不再拒绝之后的请求。
- 个别模型网关在流式工具调用里重复发送空的 id 或名称时，工具调用不再丢失名称而无法执行。
- 模型请求中途失败并重试后，失败那次已经输出的半段文字不再重复出现在本轮回复结果和子智能体摘要里。
- 点“停止”后，不理会取消的工具（例如部分 MCP 工具）不再让这一轮一直停不下来。

- 普通会话和非 Git 项目的「已编辑文件」行可以点击查看当前内容，支持 Markdown／源码、文本、代码和常见图片；缺失文件显示明确原因，不再因缺少 Git 快照禁用查看。

- 设置 › 常规新增「显示网站图标」（默认关闭）：打开后网页引用显示真实网站图标，统一正文、资源卡片与来源清单；关闭时不访问链接网站。项目外的文件引用只能在访达中显示，不读取文件内容。

- Preview 发布链升级到当前打包冒烟契约：候选包与聚合步骤要求 schema 2，并校验渲染层隔离、主机沙箱、服务就绪和 macOS 受保护目录拒读，避免旧发布脚本拒绝新产物。
- macOS Helper 能识别系统签名克隆中的 `.app.bundle` 可执行文件，修复 Chrome 明明仍在运行却未出现在应用列表的问题。

- 修复 macOS 虚拟指针的箭头尖端与轮廓被透明窗口圆角裁切的问题，并修复透明 Dock 背景造成的可见性误判；目标确实被其他窗口遮挡时仍在对话预览中显示指针。
- 对话实时预览无法启动时显示屏幕录制权限或连接原因；未签名 Preview 更新后可重置当前 Helper 的系统授权，避免旧授权开关看似开启但实际无效。
- macOS Helper 可以发现它启动之后才打开的应用；系统授权提示使用 Helper 对应图标。

### Added

- Agent 可以用新工具 `web_fetch` 读取公开网页（默认开启）：网页转成 Markdown，返回标题、跳转后的地址和正文，长页面分段读取。不带 Cookie 和登录状态，地址或跳转指向本机、内网地址时直接拒绝；单页最多读取 10 MB，超出部分会说明。网页内容按不可信的外部内容交给模型。
- 模型使用 DeepSeek 官方 API 时，Agent 可以用 `web_search` 通过 DeepSeek Search API 搜索网页（使用该模型的 API Key，按次计费）；其他供应商下没有这个工具，提示词也不再提到不存在的工具。
- 新增「设置 › 高级」，其中「网络工具」可以分别关闭网页读取和网页搜索；关闭后工具从 Agent 的工具列表和「能力 › 工具」里消失。插件 Hook 里的 `WebFetch` 匹配现在对应 `web_fetch`。

- 对话资源采用统一展示：输入框保留可编辑网址，消息使用网站／GitHub 标记与摘要卡片，环境信息卡新增「输出内容」并逐条显示来源和出处。网页详情主动展开后才加载，失败可重试；GitHub 区分仓库、PR、Issue、Commit、Release 和 CI。
- 文件图标改为逐类绘制的 SVG，统一用于消息、附件、资源清单与文件面板；文件行号支持 `#L12`、`:12`、`:12:3`，缺失文件明确显示不可用。

- 「设置 › 电脑操作 › Chrome 和 Edge › 浏览器权限」的「启用站点工具」（WebMCP）标为不可用；当前未接入站点工具，开关不能打开，模型也没有对应工具可调用。
- Agent 可以搜索你在 Chrome 和 Edge 里的浏览历史（例如找回上周看过的页面），由“设置 → 电脑操作 → Chrome 和 Edge → 浏览器权限 → 历史记录”决定：始终询问（默认，每次搜索前弹出确认卡）、始终允许，或从不（Agent 看不到这个工具）。只返回网页地址、标题与访问时间，按不可信内容处理。扩展因此新增“历史记录”权限。
- Agent 可以在你自己的 Chrome 或 Edge 里新开标签页（放进名为“Emperor”的标签组）并在已连接的标签页里跳转，按“设置 → 电脑操作 → Chrome 和 Edge → 智能体权限”办事：默认浏览允许、下载需要批准，可以按网站（`example.com`、`*.example.com` 或完整地址）设例外，每项可选允许、需要批准或阻止。阻止的网站直接拒绝；需要批准的逐次弹出确认卡；网页自己跳到阻止的网站时该标签页与 Emperor 断开，跳到需要批准的网站时暂停等你批准。Agent 标签页里的下载先停在浏览器里：可执行文件一律拦截，其余按下载规则放行、询问或取消，结果记在“下载历史记录 › Emperor 的下载”并标明来自 Chrome 还是 Edge。扩展因此新增“标签页组”和“下载”权限。

### Security

- 安装包仍不签名，但不再「不封签」：打包时翻转 Electron fuses，`ELECTRON_RUN_AS_NODE`、`NODE_OPTIONS`、`--inspect` 都不能再让 Emperor 运行别人的脚本，只从 `app.asar` 加载应用，macOS 上 `app.asar` 改动一个字节就无法启动。
- macOS 上应用和每个 Helper 的 ad-hoc 封签都带 hardened runtime，其他程序不能用 `DYLD_INSERT_LIBRARIES` 把代码注入电脑操作、听写 Helper 或 Emperor 本身来借用它们已获得的权限；entitlements 只保留必需的几项。更新到这一版后，辅助功能、屏幕录制、麦克风与语音识别需要重新允许一次。
- 打包版不再读取 `ELECTRON_RENDERER_URL`（以前可被指向任意网页并获得主窗口的全部能力），带 `--remote-debugging-port`/`--remote-debugging-pipe` 启动会直接退出。
- 打包冒烟（`--emperor-packaged-smoke`）只接受系统临时目录下的状态目录，不会再对你真实的 `~/.emperor` 运行，也不再写入应用自己的 Application Support 目录。
- 查验 Helper 签名、复制 Helper、读取浏览器密钥等系统命令一律按绝对路径执行，不受 `PATH` 影响；受限 Shell 固定使用 `/usr/bin/sandbox-exec`。
- 模型 API Key 不再明文写入 `model_config.json`：保存时用 Emperor 本地密钥加密（`el1:…`，与凭据库同一把密钥，不用钥匙串），设置页只显示末 4 位。旧版本的明文 Key 照常可用，下一次保存模型设置时自动加密，加密前的原文件保留为 `model_config.json.pre-seal-<时间>`。本地密钥丢失或被替换时，受影响的模型显示「凭据需要重新输入」，其余配置不受影响。`mcp_config.json` 里 `headers` 与 `env` 中 key、token、secret、authorization、password 类的值同样加密，连接时解开。
- Agent 的文件、搜索与 Shell 工具在任何权限模式下都不能读写 `~/.emperor` 的 `model_config.json`、`mcp_config.json`、`settings.json`、`hooks.json`（含备份），提权也不行；Agent 通过 `mcp_config`、`skill_manage` 等工具改配置，不受影响。`~/.ssh`、`~/.aws`、`~/.config/gcloud`、`~/.docker/config.json`、`~/.netrc`、`~/.codex/auth.json`、`~/.claude/.credentials.json` 不能写，读取需要你批准一次（审批卡写明文件和理由），`danger-full-access` 下可以直接读。默认预设下经 SSH 的 `git push`、`aws`、`gcloud` 等命令因此需要批准一次。`danger-full-access` 的 Shell 在 macOS 上也受这张表约束；Emperor 启动的 Codex 子任务仍能刷新自己的登录。
- 凭据库主密码：设置时要输入两次；更改或移除都要先输入当前主密码，「更改」留空不再悄悄关闭保护，「移除主密码」是单独的危险操作。连续输错 5 次后，每次重试要等待（从 5 秒起翻倍，最长 5 分钟）。
- 凭据库升级为版本 3：每个条目的绑定（网站或 App）、代填方式与字段都参与加密校验，有人改动 `vault.json` 里某个条目的绑定，这个条目就无法解密，其他条目不受影响。版本 2 的凭据库在本地密钥可用（有主密码时为第一次解锁）时自动迁移，迁移前原文件保留为 `vault.json.v2-backup-<时间>`。
- 新增「导出凭据备份」与「导入凭据备份」：全部凭据和本地密钥用你输入两次的口令（scrypt 派生密钥）加密成一个 `.emperor-vault` 文件；导入按条目合并，并先另存当前凭据库。在还没有本地密钥的 Mac 上导入时，备份里的本地密钥成为这台 Mac 的本地密钥，用它加密的模型 Key 和 MCP 令牌也能一起恢复。
- 电脑操作 Helper 的连接改为主进程先监听、Helper 主动连接：一次性密钥经 Helper 的标准输入传递（不再出现在启动参数里），双方用 HMAC 挑战应答互相证明身份。抢先连上 socket 的同用户进程拿不到任何凭据；Helper 仍核对监听方的进程号与代码身份。更新到这一版后，辅助功能与屏幕录制需要重新允许一次。
- 主窗口有了严格的内容安全策略（响应头与页面同一份）：只运行应用自带的脚本，禁止 `eval` 和内联脚本，不能向任何网络地址发请求或嵌入框架；内联样式照旧可用。
- Emperor 自己的窗口不再授予网页权限：麦克风、摄像头、屏幕、通知和设备一律拒绝，也不能下载；主窗口的复制按钮照常可用。听写在独立 Helper 里录音，不受影响。
- 打包版使用 Emperor 自己的应用菜单（关于、偏好设置… ⌘,、编辑、显示、窗口、帮助），不再提供「重新载入」和「开发者工具」，主窗口与桌宠的 DevTools 关闭；以前误按 ⌘R 会重载界面并暂停电脑操作。
- 回复里的任何链接都不会让主窗口跳转或重新加载：没有扩展名的相对路径（如 `packages/core`）以前会重载整个界面、丢掉草稿，现在交给引用解析；`mailto:`、`tel:` 交给系统；其他协议不打开并提示。
- 回复与 Markdown 预览不再自动加载远程图片（可被用作追踪像素），改为「点击加载图片 · 域名」，点击后由 Emperor 代为下载：不带 Cookie，拒绝本机和内网地址。
- 「打开文件夹」类操作（诊断、Skills）只能打开 Core 提供的文件夹，渲染层不能再让主进程打开任意路径；所有桌面 IPC 通道名集中在共享契约里。
- Git、Files 和 Terminal 由 Core 按 Build session 所有权授权；Renderer 不获得 Node/fs/shell，Git mutation 使用 revision/确认，Files 拒绝 traversal/symlink escape，Terminal 高频字节流不进入聊天或持久事件。
- Electron 主界面与桌宠现在显式运行在 renderer sandbox 中；preload 改为受构建/打包审计的最小 CommonJS，桌宠不再直接读取文件系统，packaged smoke 会真实验证 Core bridge 与受管附件协议。
- 明确 MCP、Web 与外部消息是不可信输入，Goal 完成态只能由 Core Completion Gate 提交。
- 网络调研回复只有在逐项引用本轮 verified source 并通过隔离复核后才发布；核验事件不包含 URL、正文、命令、本机路径或 reviewer prompt。
- 发布文档区分当前未签名 Preview 与尚未启用的受信 Stable 流程。
- 右侧工作台的内置浏览器运行在独立的 sandboxed `WebContentsView` 与不落盘的内存分区中，只加载你在地址栏提交的 `http(s)` 地址，拒绝权限请求、下载和应用内弹窗，关闭后清空浏览数据；旧的内嵌预览通道与 `previewId` 授权路径已删除。
- 电脑操作：页面改成明文的密码框、普通输入框里的验证码，以及代填凭据后整页的输入值都不再出现在 Agent 的观察结果中；跨源 iframe 内的动作按 iframe 自己的网站授权；以点结尾的可执行文件名不再绕过下载拦截；受限 Shell 不能读取 `~/.emperor/browser/`；授权记录损坏时明确显示为已暂停。
- `gh` 只以固定参数调用，仓库、PR 编号和搜索文本先经校验再作为单个参数传入；Emperor 不向 `gh` 传递 `GH_TOKEN`、`GITHUB_TOKEN` 等 token 环境变量，Pull Request 页不执行任何写操作。
- Agent 的 `read`、`edit`、`write`、`grep`、`glob` 工具在任何权限模式下都不能读取或修改 `~/.emperor/computer-use/`（凭据库、本地密钥、浏览器配对、授权记录）与 `~/.emperor/browser/`（登录状态 profile、下载收件箱等）：按真实路径判断，从上级目录搜索时略过，与受限 Shell 的 Seatbelt 规则共用一份目录表；这两个目录启动时设为 0700。
