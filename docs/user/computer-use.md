# 电脑操作（实验）

> 文档状态：Active<br>
> 面向读者：使用 macOS Preview 的用户与测试者<br>
> 最后核验：2026-09-29<br>
> 事实源：`desktop/src/renderer/src/components/settings/ComputerUseSection.vue`、`desktop/src/renderer/src/components/settings/computer/`、`desktop/src/main/computer-use/`、`packages/core/src/harness/computer-use/`

在“设置 → 电脑操作”打开总开关后，Agent 才能使用图形界面工具。页面分别显示内置浏览器、外部浏览器连接和 macOS 桌面驱动的实际状态与缺失能力，每个驱动旁还有单独的开关：关掉某个驱动后，Agent 调用它会得到“能力未启用”，已打开的对应目标随之结束。各驱动仍处于实验阶段；总开关开启不等于所有驱动均已连接或获得系统权限。

## 内置浏览器

工作台的普通“浏览器”供你自己查看网页；Agent 受控标签页由电脑操作服务管理。Agent 使用 `browser_open` 打开页面后，可在工作台浏览器面板查看和接管该标签页。页面内容作为不可信数据处理，操作要求当前目标、授权和观察所得的引用仍有效；页面导航或重载后，Agent 需要重新观察。

默认使用临时 profile。你可以在“设置 → 电脑操作 → 浏览器 profile”新建持久 profile，以保留网站 Cookie 和登录状态。清空或删除 profile 会关闭它的标签页、清理浏览数据并撤销关联授权。应用重启后恢复的标签页具有新的目标身份，旧引用不会继续有效。

摄像头、麦克风、位置、通知、剪贴板和全屏默认拒绝。需要某项网站权限时，在“网站权限”中选 profile、填写完整 origin（如 `https://example.com`）与权限，可设置到期分钟数；删除授权可立即撤销。高影响操作逐次确认。跨源 iframe 支持定位、观察与点击，按该 iframe 自己的网站授权：对页面的授权不会覆盖其中嵌入的支付或登录框，授权卡片会注明它嵌在哪个页面里。iframe 中的文本输入仍不可用，你接管后也无法在其中输入，请改在自己的浏览器中完成。截图坐标操作也未开放。

你接管或暂停某个标签页时，页面弹出的新窗口也保持在你手里，需你交还后 Agent 才能操作。

### 下载与上传

普通上传和下载按电脑操作授权模式执行。上传只使用你在系统对话框中亲自选择的文件。下载只进入 Emperor 的下载收件箱（`~/.emperor/browser/downloads/`），可执行文件和安装包（包括以点结尾等变形文件名）一律拒绝，会话记录会写下下载地址、文件类型、发起页面、大小与 SHA-256。在工具行中可以“在访达中显示”“移到工作区”（放到当前对话工作区的 `downloads/` 下）或“另存为…”；应用重启后这些操作仍可用。收件箱中的文件按“设置 → 电脑操作 → 截图与下载”中的保留时间（默认 30 天，可选 7 / 30 / 90 天或一直保留）自动删除，已移走的文件不受影响。

### 截图

Agent 截图时，给你看的原图与给模型的压缩图都保存为附件。每个对话最多保留 200 张或 200 MB，全部对话合计 2000 张或 2000 MB，超出时先删除最早的截图；“截图与下载”中的“全部清除”可一次删除。被删除的截图在对话中显示为已清除，模型回看时只会读到“附件已清除”。

## 凭据

代填账号密码后，页面上所有输入框的值在 Agent 的观察结果中一律显示为“有内容”，直到页面跳转；页面把密码框改成明文、或把验证码放在普通输入框时，这些值同样不会给 Agent 看到。Agent 通过普通“填写”输入的文字会进入任务记录，工具行会提示这一点。

“凭据”设置区可保存网站或 macOS App 凭据，并可选择至少 12 字符的主密码。设置了主密码后，启动及空闲 30 分钟后需要重新解锁；可勾选“允许 Touch ID 解锁”，之后锁定时用 Touch ID 或登录密码解锁（更改或移除主密码会让这一设置失效）。设置区会显示当前的加密方式与保护强度，以及每个条目上次代填的时间和目标（不含任何值）。一起保存 TOTP 密钥时会提示两步验证因此退化为一步；编辑时可以删除已保存的 TOTP 密钥。未签名 App 的绑定只能按 Bundle ID 与路径识别，设置区会标注“身份校验较弱”。网站绑定使用完整 origin；App 绑定使用 Bundle ID，加 Team ID 或应用绝对路径。每次代填账号、密码或验证码前都会暂停确认并再次核对目标身份；旧条目即使保存为“自动”也按此规则执行。网址或应用与登记不一致、目标字段类型不符（例如要把密码填进普通文本框），或系统加密不可用时，会在弹出确认前直接拒绝，其中网址不一致会在工具行醒目提示可能是仿冒页面。拒绝一次代填确认只会阻止同一任务中该站点的后续代填，不影响普通操作。模型只得到凭据名称和句柄，不接收密码、TOTP 密钥或主密码。查看密码只在设置区进行，并在 30 秒后隐藏。

桌面密码框能否由辅助功能写入取决于目标 App。若 Helper 已尝试写入却无法回读，操作会报告结果未知；不要立即重试，应由你检查目标窗口。该目标后续截图会被停用，直到目标释放。

## macOS 桌面

macOS 驱动通过独立的 Emperor Computer Helper 运行。在“设置 → 电脑操作”查看其连接、辅助功能和屏幕录制状态。点击相应的“请求权限”，再到系统设置开启开关；若“录屏与系统录音”列表没有 Helper，可用“＋ 添加”选择 `~/.emperor/native-helpers/` 中当前安装版本的 `Emperor Computer Helper.app`。屏幕录制用于截图和被控窗口的实时预览。授权可能需要重启 Helper 才生效；状态为拒绝或失效时，设置页提供需再次确认的“重置授权”。

macOS 的系统录屏授权按应用生效。如果你也向 Emperor Agent 主应用打开“录屏与系统录音”，它启动的 Shell 子进程可能直接截图，不受电脑操作的目标授权约束。本机实验已在“工作区”预设下复现；当前受限 Shell 的 Seatbelt 规则没有阻止该截图。需要将桌面录屏权限限定在 Helper 时，请核对系统设置中主应用的开关状态。

macOS Preview 使用 ad-hoc 签名。每次更新后 Helper 的代码身份可能改变，需要重新授予辅助功能和屏幕录制；即使系统开关仍显示开启，也应以设置页读取到的 Helper 权限状态为准。设置页会固定提示这一点。

桌面驱动目前标为**实验**。设置页按连接和权限显示可用动作及未完成的能力。辅助功能可用于列出 App、窗口和读取控件；截图还需要屏幕录制授权。对已观察到的下拉框，`desktop_select` 按精确选项名称操作，并要求重新观察其值。常用动作已在文本编辑、终端、计算器、VS Code 和 Emperor 测试 App 上实测；没有自动的用户活动检测，桌面凭据代填只在测试 App 上验收过。你可以使用手动接管或全局急停；不要依据“已授权”推断动作一定成功。

Agent 默认在后台操作：按下控件、写入文本框、执行菜单命令，以及把按键直接发给原生 App，都不移动你的鼠标，也不切换前台，你可以继续使用电脑。另一个桌面空间里的窗口同样可以读取。少数步骤只能在前台完成：Chrome、Edge 和 Electron 应用（如 VS Code）在后台会忽略按键并把菜单变灰；原生 App 的“撤销”“关闭”“全选”等作用于当前窗口的命令在后台也不可用；按坐标的点击和拖动需要窗口在前。开启“持续允许电脑操作”时，这些步骤会把目标窗口切到前台：原生 App 执行完该命令立即把前台还给你原来的 App，其余情况在任务结束时交还（你已切到别处时不再切回）。关闭持续允许时，每个任务第一次需要前台前会先询问。macOS 有时会拒绝这种切换，例如系统弹窗在前时，此时该步骤不会发送。

Agent 控制某个窗口期间，Helper 持续录制该窗口：macOS 会在窗口左上角显示紫色的共享标记，并在菜单栏显示共享状态，工作台的“电脑”面板显示该窗口的实时缩略图。在菜单栏点“停止共享”等同接管，Agent 暂停操作该窗口，你在面板中交还后可继续。敏感应用不录制；代填凭据后，该目标也不再录制和预览。Agent 点击或拖动时，屏幕上会在落点显示一个箭头，你的鼠标保持不动；落点被其他窗口挡住时不显示。

复杂应用的控件可能嵌套较深。`desktop_observe` 默认读取到第 8 层；若结果提示 `truncated`，Agent 可对同一目标指定 `maxDepth: 16` 再观察，或按控件角色、名称缩小范围。深度上限为 16，结果仍截断时不能假定未显示的控件不存在。

在“设置 → 电脑操作 → 应用名单”中，你可以按 bundle ID 追加三类应用：

- **保护的应用**：Agent 在应用和窗口列表中看不到它们，也不能绑定或操作，例如密码管理器、网银客户端。系统授权界面、钥匙串、密码 App、系统设置与 Emperor 自身已内置保护。
- **高风险应用**：终端与脚本类应用已内置。关闭“持续允许”时，每一次输入都要单独确认；凭据代填与高影响操作在任何模式下都逐次确认。
- **敏感应用**：只读取界面结构，不读取输入框内容，也不截图。

工作台的“电脑”面板列出当前会话已绑定的桌面窗口、最近截图和控制状态。暂停、接管、交还与结束操作使用统一的目标控制接口；结束操作释放目标绑定，不关闭原应用窗口。面板会列出当前驱动缺失的能力。

## Chrome 扩展连接

外部浏览器驱动只处理你在扩展中主动连接的标签页。开发预览需要先将 [`desktop/extension/`](../../desktop/extension/) 作为未打包扩展加载（扩展 ID 固定为 `oobcokoopgkhlhpohfdpelkafiidojjn`），再在安装版 Emperor 的“设置 → 电脑操作 → Chrome / Edge 扩展”中点击“连接 Chrome/Edge”：它会为本机用过的 Chrome 与 Edge 登记连接，此后每次启动都会指向当前安装的 Emperor；撤销最后一个配对时，登记随之删除。开发版无法登记，可按[原生消息 host 说明](../../desktop/native/browser-host/README.md)手动操作。同一用户同时只有一个 Emperor 可以占用浏览器连接；若另一个实例正在使用，本应用仍能启动，并在旧实例退出后约每 5 秒重试，设置页会更新状态。扩展弹窗的“开始配对”会显示六位验证码；必须与 Emperor“设置 → 电脑操作 → Chrome / Edge 扩展”中的验证码一致，才在 Emperor 中点击确认。之后，扩展会针对当前网站的精确 origin 请求权限，并由你选择“连接当前标签页”。“已连接 Emperor”只表示浏览器与应用配对成功；设置页另列“可操作标签页”数量，只有该数量大于零时 Agent 才能认领标签页。

此通道目前只提供主框架的语义观察与受限点击、填写；截图、跨源 frame、上传、下载和坐标动作未开放。扩展不使用 Chrome 的调试协议，因此安装时不会出现调试权限警告，浏览器顶部也不会出现“正在调试此浏览器”的提示条。扩展重载、断连或标签页替换后应重新观察，旧目标和元素引用不得复用。Edge 尚无本机验收证据。

## 授权、接管与急停

每次操作都经过同一个电脑操作服务：它检查会话主体、目标租约、当前目标身份、授权和观察版本，并在会话日志中记录脱敏的动作状态。你可在设置页撤销网站或 App 授权，也可以只去掉某个授权中的一项动作或一个网站（去掉最后一项即撤销）。

在 macOS 上按 **⌃⌥⌘.** 触发全局急停；快捷键可在“紧急停止”中修改或恢复默认。开启电脑操作期间，程序坞菜单里也有“停止电脑操作”；快捷键被其他应用占用时，菜单栏会多出一个停止图标。急停会取消进行中的动作、暂停目标、挂起授权并让 Helper 松开按住的键和鼠标；恢复需要在设置页操作。授权记录文件损坏时，Emperor 会隔离它、挂起全部授权，设置页显示“已暂停”并说明原因，恢复后需要重新授权。

“持续允许电脑操作”是持久设置，与会话的 Shell 权限独立。开启时，普通观察、交互、输入、跳转、上传和下载自动放行，包含本机及局域网网站和终端等应用，桌面窗口需要前台时也直接切换。凭据代填、付款、发送、删除、退出应用、丢弃未保存内容等高影响动作仍逐次确认；关闭窗口不算高影响，未保存的内容由 App 自己询问；急停、系统权限、目标身份与版本检查仍有效。关闭持续允许后，普通操作按目标和动作逐项授权。完全放行的 Shell 另有能力执行电脑操作服务以外的命令，因此电脑操作总开关不构成 Shell 的浏览器限制。子代理仍以自己的身份和目标租约操作。

连接、权限或目标过期时，先看设置页各驱动的诊断行和缺失能力，再参考[诊断与排障](diagnostics-troubleshooting.md)。
