# 电脑操作（实验）

> 文档状态：Active<br>
> 面向读者：使用 macOS Preview 的用户与测试者<br>
> 最后核验：2026-10-15<br>
> 事实源：`desktop/src/renderer/src/components/settings/ComputerUseSection.vue`、`desktop/src/renderer/src/components/settings/computer/`、`desktop/src/renderer/src/components/settings/BrowserSettingsSection.vue`、`desktop/src/renderer/src/components/settings/browser/`、`desktop/src/renderer/src/components/conversation/computer-use/`、`desktop/src/main/computer-use/`、`packages/core/src/harness/computer-use/`

在“设置 → 电脑操作”打开总开关后，Agent 才能使用图形界面工具和 `computer-use` Skill。「能力 › 插件」里的 Computer Use 插件是同一个开关，两处看到的状态始终一致，插件详情还列出各驱动的实际状态。打开后由 Agent 连续操作：观察、点击、输入（包括终端）、跳转、上传和下载都直接进行，只有高影响操作、代填账号密码，或 Agent 需要你决定时才会停下来等你（见[确认与任务结束](#确认与任务结束)）。

页面布局参照 Codex 的“电脑操控”，除 Chrome 连接外都在这一页：

- 出问题时，最上面出现一张提醒卡，写明缺什么、怎么修，修复按钮就在卡里：Emperor Computer Helper 未连接时是“重新连接”；缺辅助功能或屏幕录制权限时是“请求权限”，缺屏幕录制时还有“重启 Helper”。一切正常时不显示。
- 总开关卡片。
- “控制”一组有“任意应用”（macOS 桌面）和“Chrome 和 Edge”（扩展连接）两行，各有单独的开关：关掉某一个后，Agent 调用它会得到“能力未启用”，已打开的对应目标随之结束。只在不是“可用”时，名称旁标“实验”或“不可用”；总开关开启不等于所有驱动均已连接或获得系统权限。缺权限时，“任意应用”一行会写明缺哪一项。“Chrome 和 Edge”的“管理”打开扩展连接页，见[Chrome 扩展连接](#chrome-扩展连接)。
- “系统权限”：辅助功能和屏幕录制都已允许时只有一行；否则逐项显示，并列出 Helper 的版本与最近错误码。
- “截图”：已保存截图的张数和大小，可“全部清除”。

Emperor 可以操作所有应用，只有受系统保护的应用除外（见[macOS 桌面](#macos-桌面)）。没有应用名单，也没有紧急停止：要让 Agent 停下，在对话里停止回合或关掉总开关。从旧版本升级时，如果你以前在“不让 Emperor 操作的应用”里加过应用，页面顶部会提示一次这些应用现在可以操作，点“知道了”后不再出现。

“Chrome 和 Edge”页的页头是“电脑操作 › Chrome 和 Edge”，点“电脑操作”返回。内置浏览器的开关在“设置 → 浏览器”顶部的“浏览器 · 让 Emperor 控制内置浏览器”；登录状态（浏览器 profile）、网站设置、密码管理器和下载保留时间也在“设置 → 浏览器”。

## 对话中的预览

Agent 操作的窗口和标签页以只读预览显示在对话右下角：最新操作的目标叠在最上面，多个目标错位堆叠，点下面露出的条可以把那张卡片提到前面。桌面窗口和内置浏览器标签页有实时画面；已连接的 Chrome 标签页没有画面，卡片注明“暂无截图”。预览只用来看，没有暂停、接管或交还按钮；要让 Agent 停下，见[确认与任务结束](#确认与任务结束)。Agent 在桌面窗口或内置浏览器标签页中点击、填写、选择、滚动或拖动时，这张卡片的实时画面上会在落点画一个与屏幕上相同的箭头，约 2 秒后淡出；窗口被挡住时也照样画。系统开启“减少动态效果”时，箭头直接出现在新位置，不做移动动画。已连接的 Chrome 标签页不画箭头。

对话栏较窄时，预览收成一个带数量的小标签，点开才订阅画面。代填过凭据的目标不显示画面，卡片会写明原因。

## 内置浏览器

工作台的普通“浏览器”供你自己查看网页；Agent 的标签页由电脑操作服务管理，在对话预览中查看，不出现在工作台里。页面内容作为不可信数据处理，操作要求当前目标、授权和观察所得的引用仍有效；页面导航或重载后，Agent 需要重新观察。

默认使用临时 profile。你可以在“设置 → 浏览器 → 登录状态”点“新建”，建一个持久 profile，以保留网站 Cookie 和登录状态。清空或删除 profile 会关闭它的标签页、清理浏览数据并撤销关联授权。应用重启后恢复的标签页具有新的目标身份，旧引用不会继续有效。

摄像头、麦克风、位置、通知、剪贴板和全屏默认拒绝。需要某项网站权限时，在“设置 → 浏览器 → 网站设置”点“放行”，填写完整 origin（如 `https://example.com`）、选权限和 profile，可设置有效分钟数；点“撤销”立即收回。跨源 iframe 支持定位、观察与点击。iframe 中的文本输入仍不可用，请改在自己的浏览器中完成；截图坐标操作也未开放。

Agent 的标签页在后台离屏渲染，你无法在其中直接输入。需要密码时，把它存进“设置 → 浏览器 → 密码管理器”再由 Agent 按句柄代填，或在自己的浏览器里完成那一步。

应用窗口重载期间，Agent 的标签页会暂停，窗口加载完成后自动继续；这期间页面弹出的新窗口同样随之继续。

### 下载与上传

普通上传和下载直接进行。上传只使用你在系统对话框中亲自选择的文件。下载只进入 Emperor 的下载收件箱（`~/.emperor/browser/downloads/`），可执行文件和安装包（包括以点结尾等变形文件名），以及打开时会运行命令或启动本机应用的 macOS 文件（如 `.terminal`、`.fileloc`、`.webloc`、AppleScript），一律拒绝，会话记录会写下下载地址、文件类型、发起页面、大小与 SHA-256。在工具行中可以“在访达中显示”“移到工作区”（放到当前对话工作区的 `downloads/` 下）或“另存为…”；应用重启后这些操作仍可用。收件箱中的文件按“设置 → 浏览器 → 下载保留时间”（默认 30 天，可选 7 / 30 / 90 天或一直保留）自动删除，已移走的文件不受影响。“设置 → 浏览器 → 下载历史记录”的“Emperor 的下载”也列出这些文件，可以做同样的三项操作。

### 截图

Agent 截图时，给你看的原图与给模型的压缩图都保存为附件。每个对话最多保留 200 张或 200 MB，全部对话合计 2000 张或 2000 MB，超出时先删除最早的截图；“设置 → 电脑操作 → 截图”的“全部清除”可一次删除。被删除的截图在对话中显示为已清除，模型回看时只会读到“附件已清除”。

## 凭据

代填账号密码后，页面上所有输入框的值在 Agent 的观察结果中一律显示为“有内容”，直到页面跳转；页面把密码框改成明文、或把验证码放在普通输入框时，这些值同样不会给 Agent 看到。Agent 通过普通“填写”输入的文字会进入任务记录，工具行会提示这一点。

“设置 → 浏览器 → 密码管理器”可保存网站或 macOS App 凭据（右上角“添加”，每条可“编辑”“删除”），并可在“主密码”一行设置至少 12 字符的主密码（输入两次，两次不一致时不保存）。设置了主密码后，启动及空闲 30 分钟后需要重新解锁；忘记主密码就无法找回已保存的密码。“更改”要先输入当前主密码，新密码同样输入两次，不能用留空的方式关闭保护；“移除主密码”是单独的按钮，同样要输入当前主密码，移除后已保存的密码只由本地密钥保护。主密码连续输错 5 次后，每次重试要等待一段时间（从 5 秒起翻倍，最长 5 分钟）。凭据用 Emperor 本地密钥加密，这把密钥保存在这台 Mac 的 Emperor 目录（`~/.emperor/computer-use/secrets/local.key`），不使用 macOS 钥匙串，也不会弹出钥匙串授权框（只有“从 Chrome/Edge 导入”读取那个浏览器自己的钥匙串项目时例外）。以你身份运行的程序也能读到这把密钥，所以只有本地密钥时设置区标为“基础”保护，建议再设主密码。本地密钥及其所在目录只要求属于你、其他用户无权访问，用 `chmod -R 700` 收紧权限后照常可用；如果其他用户也能读取，Emperor 会暂停使用它，设置区顶部提示“本地密钥的权限过宽”，点“修复权限”恢复为只有你能读写即可，已保存的密码不受影响。本地密钥丢失（或属主、内容不对）时，已保存的密码无法解密，设置区顶部会提示，可以“从备份恢复”，或确认后“清空”重新开始。凭据库文件 `vault.json` 损坏或由更新版本的 Emperor 写入时，应用照常启动，只是暂时不能代填；设置区顶部提示“凭据库无法读取”（更新版本写入的只列出名称），原文件保持不变，可以“从备份恢复”，或“重新开始（先备份）”：原文件另存为 `vault.json.unreadable-<时间>`（或 `.newer-<时间>`）后从空的凭据库开始。“备份”一组里的“导出…”把全部凭据和本地密钥用你输入两次的口令（至少 12 个字符）加密成一个 `.emperor-vault` 文件，保存位置在系统对话框里选；“导入…”选好文件后输入口令，备份里的凭据按条目合并进来（同一条以备份为准），导入前当前的凭据库会另存一份。在一台还没有本地密钥的 Mac 上导入时，备份里的本地密钥会成为这台 Mac 的本地密钥。忘记备份口令就无法从这个备份恢复。每个条目的网站或 App 绑定、代填方式都参与加密校验，有人直接改动 `vault.json` 里的绑定，这个条目就无法解密。以前版本用钥匙串加密的密码在升级后清除，需要时重新添加或导入。设置区会显示当前的加密方式与保护强度，以及每个条目上次代填的时间和目标（不含任何值）。一起保存 TOTP 密钥时会提示两步验证因此退化为一步；编辑时可以删除已保存的 TOTP 密钥。未签名 App 的绑定只能按 Bundle ID 与路径识别，设置区会标注“身份校验较弱”。网站绑定使用完整 origin；签名 App 按 Bundle ID 与 Team ID 绑定。若额外填写路径，或为未签名 App 使用路径绑定，必须填写进程可执行文件的绝对路径（如 `/Applications/Example.app/Contents/MacOS/Example`），不能只填 `.app` 目录；Team ID 和路径同时填写时，两者都必须匹配。每次代填账号、密码或验证码前都会弹出确认卡，只允许这一次，并再次核对目标身份。网址或应用与登记不一致、目标字段类型不符（例如要把密码填进普通文本框），或本地加密不可用时，会在弹出确认前直接拒绝，其中网址不一致会在工具行醒目提示可能是仿冒页面。拒绝一次代填确认只会阻止同一任务中该站点的后续代填，不影响普通操作。模型只得到凭据名称和句柄，不接收密码、TOTP 密钥或主密码。查看密码只在设置区进行，查看前要用 Touch ID 或 Mac 登录密码确认身份，30 秒后隐藏。Agent 的受限 Shell 和读写、搜索文件的工具都不能读取 `~/.emperor/computer-use/` 与 `~/.emperor/browser/`。

没有保存的凭据时，Agent 会用提问卡片请你在目标窗口里自己输入，完成后再继续；它不会在对话里向你索要密码。

桌面密码框能否由辅助功能写入取决于目标 App。若 Helper 已尝试写入却无法回读，操作会报告结果未知；不要立即重试，应由你检查目标窗口。该目标此后不再显示预览画面，直到它被释放。

## macOS 桌面

macOS 驱动通过独立的 Emperor Computer Helper 运行。在“设置 → 电脑操作 → 系统权限”查看辅助功能和屏幕录制状态。缺权限时，页面顶部的提醒卡有“请求权限”，点后到系统设置打开开关；列表里没有 Helper 时，点“＋”，按 ⌘⇧G 输入 `~/.emperor/native-helpers/`，选择当前安装版本的 `Emperor Computer Helper.app`。屏幕录制用于截图和对话中的实时画面，打开开关后点“重启 Helper”生效。状态为未允许或需重启时，“系统权限”标题旁有需再次确认的“重置授权”。Emperor 启动 Helper 时先在自己的 `~/.emperor/run/` 里监听一个新的 socket，再把一次性密钥经 Helper 的标准输入交给它（不出现在启动参数里）；Helper 连上后双方用这把密钥做 HMAC 挑战应答，答不出的连接会被直接断开，所以抢先连上 socket 的其他程序拿不到任何凭据。

macOS 的系统录屏授权按应用生效。如果你也向 Emperor Agent 主应用打开“录屏与系统录音”，它启动的 Shell 子进程可能直接截图，不受电脑操作的目标授权约束。本机实验已在“工作区”预设下复现；当前受限 Shell 的 Seatbelt 规则没有阻止该截图。需要将桌面录屏权限限定在 Helper 时，请核对系统设置中主应用的开关状态。

macOS Preview 使用 ad-hoc 签名。每次更新后 Helper 的代码身份可能改变，需要重新授予辅助功能和屏幕录制；即使系统开关仍显示开启，也应以设置页读取到的 Helper 权限状态为准。缺权限时的提醒卡会提示这一点。

桌面驱动目前标为**实验**。辅助功能可用于列出 App、窗口和读取控件；截图还需要屏幕录制授权。对已观察到的下拉框，`desktop_select` 按精确选项名称操作，并要求重新观察其值。常用动作已在文本编辑、终端、计算器、VS Code 和 Emperor 测试 App 上实测；没有自动的用户活动检测，桌面凭据代填只在测试 App 上验收过。不要依据“已开启”推断动作一定成功。

Agent 默认在后台操作：按下控件、写入文本框、执行菜单命令，以及把按键直接发给原生 App，都不移动你的鼠标，也不切换前台，你可以继续使用电脑。另一个桌面空间里的窗口同样可以读取。少数步骤只能在前台完成：Chrome、Edge 和 Electron 应用（如 VS Code）在后台会忽略按键并把菜单变灰；原生 App 的“撤销”“关闭”“全选”等作用于当前窗口的命令在后台也不可用；按坐标的点击和拖动需要窗口在前。这些步骤会直接把目标窗口切到前台：原生 App 执行完该命令立即把前台还给你原来的 App，其余情况在任务结束时交还（你已切到别处时不再切回）。macOS 有时会拒绝这种切换，例如系统弹窗在前时，此时该步骤不会发送。

Agent 控制某个窗口期间，Helper 持续录制该窗口：macOS 会在窗口左上角显示紫色的共享标记，并在菜单栏显示共享状态，对话预览显示该窗口的实时画面。在菜单栏点“停止共享”只停止这个画面，Agent 继续操作该窗口；预览保留最后一帧并注明“画面已停止共享”，这次绑定期间不再重新录制。代填凭据后，该窗口不再录制和预览。Agent 点击或拖动时，屏幕上会在落点显示一个箭头，你的鼠标保持不动；落点被其他窗口（包括 Emperor 自己）挡住时，屏幕上不显示，箭头改在[对话预览](#对话中的预览)的实时画面上看。

复杂应用的控件可能嵌套较深。`desktop_observe` 默认读取到第 8 层；若结果提示 `truncated`，Agent 可对同一目标指定 `maxDepth: 16` 再观察，或按控件角色、名称缩小范围。深度上限为 16，结果仍截断时不能假定未显示的控件不存在。

**允许操作的应用范围。** 除内置保护的应用外，Agent 可以尝试操作其他应用；能否观察到控件、执行动作或保持后台取决于目标 App 和系统状态，不保证覆盖所有应用。受保护的有系统授权弹窗与密码框、钥匙串访问、“密码” App、系统设置、登录窗口和 Emperor 自身：它们不出现在应用和窗口列表里，也不能绑定或操作。这份名单不能修改，用来防止 Agent 替自己开权限或输入你的密码。终端和脚本类应用与其他应用一样：普通输入不单独确认，高影响操作与凭据代填照常逐次确认。向终端输入等于在命令沙箱之外执行命令，交给 Agent 前请想清楚。

## Chrome 扩展连接

外部浏览器驱动只处理你在扩展中主动连接的标签页。扩展随 Emperor 安装包提供，不在 Chrome 应用商店上架；Chrome 和 Edge 用同一个扩展。在“设置 → 电脑操作”中点“Chrome 和 Edge”一行的“管理”打开这一页：页头显示状态（未安装扩展、已安装 · 未连接、已连接 N 个浏览器或有配对等待确认），右上角是“安装扩展程序”（装进浏览器后为“重新安装扩展程序”）和“移除扩展程序”。

还没有浏览器配对时，“安装扩展”一组按四步引导，做完一步打一个勾：

1. 点“安装扩展程序”，扩展放进 `~/.emperor/browser-extension/`（可“在访达中显示”“拷贝路径”），同时为本机用过的 Chrome 和 Edge 登记与 Emperor 的连接。
2. 在 Chrome 或 Edge 的地址栏粘贴扩展页地址（`chrome://extensions` 或 `edge://extensions`，点“拷贝地址”；浏览器不允许其他应用直接打开这个页面），打开右上角的“开发者模式”。
3. 点“加载已解压的扩展程序”，选择上面的文件夹，也可以把文件夹直接拖进扩展页；选择框里按 ⌘⇧G 可以粘贴路径。
4. 扩展装好后会自动打开引导页：点“允许访问网站”（浏览器只问这一次），扩展随即向 Emperor 发起配对。Emperor 会打开这一页（程序坞图标跳动），核对验证码与引导页上的一致后点“允许”。

“连接”一组按 Google Chrome、Microsoft Edge 列出：已连接的显示可操作标签页数，可以“断开”；浏览器没打开时，已保存的配对显示“未连接”，可以“撤销”；新的配对请求也在这里，带验证码和“允许”“拒绝”。断开后扩展会清掉自己的配对，要再连接时点工具栏里的 Emperor 图标，在弹窗里点“开始配对”；Emperor 不再认识某个配对时（例如配对记录被清空），扩展会自动重新打开引导页。如果扩展是从别的文件夹加载的（例如以前直接加载仓库里的 `desktop/extension/`），页面会提醒你在扩展页移除它，再从 Emperor 的文件夹加载，这样它才会随 Emperor 升级。

升级 Emperor 时扩展文件夹自动更新，已连接的扩展自己重新加载。“移除扩展程序”会先确认，然后让已连接的浏览器自动卸载扩展，并删除扩展文件夹、全部配对和连接登记；当时没打开的浏览器，需要在它的扩展页手动移除。开发版无法登记连接，可按[原生消息 host 说明](../../desktop/native/browser-host/README.md)手动操作。同一用户同时只有一个 Emperor 可以占用浏览器连接；若另一个实例正在使用，本应用仍能启动，并在旧实例退出后约每 5 秒重试。

配对后，在要让 Emperor 操作的网页上点工具栏里的 Emperor 图标，再点“连接当前标签页”。“电脑操作”主页的“Chrome 和 Edge”一行显示“已连接 N 个浏览器 · M 个可操作标签页”，只有可操作标签页大于零时 Agent 才能认领标签页。

此通道提供主框架的语义观察、受限点击和填写，以及新开标签页、跳转和受规则约束的下载（见下节）；截图、跨源 frame、上传和坐标动作未开放。扩展不使用 Chrome 的调试协议，因此安装时不会出现调试权限警告，浏览器顶部也不会出现“正在调试此浏览器”的提示条。扩展重载、断连或标签页替换后应重新观察，旧目标和元素引用不得复用。Edge 尚无本机验收证据。

### 智能体权限：在 Chrome 和 Edge 里打开、跳转和下载

Agent 可以在你自己的 Chrome 或 Edge 里新开标签页（`external_tab_open`），用于你已登录的网站：标签页在后台打开，放进名为“Emperor”的标签组，直接交给当前任务；同时连着两个浏览器时，用最近连接的那个。在它打开的或你连接的标签页里，Agent 也可以用 `browser_navigate` 跳到别的网址（只支持具体网址，不支持后退、前进和刷新）。

“设置 → 电脑操作 → Chrome 和 Edge → 智能体权限”决定 Agent 能去哪些网站、能否下载。默认一行为“浏览：允许，下载：需要批准”，可以修改但不能删除；可以按网站添加例外，每项选“允许”“需要批准”或“阻止”。网站可以写成 `example.com`（只这个主机）、`*.example.com`（这个主机及其所有子域名）或 `https://example.com:8443`（只这个协议、主机和端口，填完整网址时只取到端口为止）；同时符合几条时，最具体的一条生效：完整地址优先，其次是主机，再次是后缀最长的 `*.`。表里只显示你添加了例外的网站。规则保存在 `~/.emperor/computer-use/external-site-rules.json`（只有你能读写），不写进 `config.json`。放宽权限的修改在有待处理的确认卡或 Plan 模式下会被拒绝，收紧不受限制。

- **打开和跳转之前**按“浏览”一栏处理：允许的直接进行；需要批准的弹出确认卡，只允许这一次；阻止的直接拒绝，Agent 会得知网站被你阻止，不会换别的办法去。
- **网页自己跳转**（点了链接、提交表单后跳转、重定向）时，跳到允许的网站，Agent 在新页面继续（先重新观察）；跳到阻止的网站，这个标签页立即与 Emperor 断开，浏览器里的页面照常显示；跳到需要批准的网站，这个标签页暂停，等你在确认卡上批准，拒绝就断开。没有任务在用的标签页跳到需要批准的网站时不弹卡，下次 Agent 要接手它时再问。
- **下载**：Agent 所在标签页触发的下载先停在浏览器里，等 Emperor 决定。可执行文件和安装包（与收件箱同一套规则）一律拦截；其余按“下载”一栏，网页所在网站与文件所在网站取更严格的一条：允许的直接下载，需要批准的弹出确认卡，阻止的取消。允许的文件保存在浏览器自己的下载文件夹，不进 Emperor 收件箱。结果记在“设置 → 浏览器 → 下载历史记录”的“Emperor 的下载”里，标注“来自 Chrome”或“来自 Edge”以及结果（大小、已拦截及原因、未批准或下载中断），这些行没有文件操作。
- **怎样认定是 Agent 的下载**：浏览器不告诉扩展下载来自哪个标签页，Emperor 按“发起下载的页面与 Agent 正在操作的标签页是同一网站，且 Agent 在一分钟内在那里观察、操作或跳转过”来认定。因此这一分钟内，你在同一网站的另一个标签页里下载的文件也会按规则处理；没有来源信息的下载（例如 `data:` 链接或隐藏了来源的链接）无法认定，由浏览器照常下载。

扩展为此需要“标签页组”和“下载”两项权限，随扩展更新一起生效。要打开或跳到扩展没有访问权限的网站时，Agent 会得知需要在扩展里允许访问网站。

### 浏览器权限：历史记录与站点工具

“设置 → 电脑操作 → Chrome 和 Edge → 浏览器权限”的“历史记录”决定 Agent 能否搜索你在 Chrome 和 Edge 里的浏览历史（`external_history_search`，例如找回上周看过的页面）：

- **始终询问**（默认）：每次搜索前弹出确认卡，写明要搜什么，只允许这一次；拒绝后，本任务里再搜索会直接被拒绝。
- **始终允许**：直接搜索。
- **从不**：Agent 根本看不到这个工具；旧对话里的调用也会被拒绝。

搜索同时查所有已连接的浏览器，只返回网页（`http`、`https`），同一地址只留最近一次访问，最新的在前；默认查最近 30 天、最多 20 条（最多 90 天、100 条）。网页标题和地址按不可信内容交给 Agent。子代理不能弹确认卡，在“始终询问”下会被拒绝。扩展为此需要“历史记录”权限；改成“从不”不会收回这项权限，只是 Emperor 不再使用。

“启用站点工具”指网站通过 WebMCP 公开给智能体的操作（例如“搜索航班”“加入购物车”）。Emperor 当前未接入这些操作：这一行标为“不可用”，开关不能打开，模型也没有站点工具可调用。网站或浏览器自身支持 WebMCP，不等于 Emperor 已能使用；以此页的实际能力状态为准。

## 确认与任务结束

每次操作都经过同一个电脑操作服务：它检查会话主体、目标租约、当前目标身份和观察版本，并在会话日志中记录脱敏的动作状态。电脑操作与会话的 Shell 权限独立：打开总开关即允许 Agent 连续操作，包括本机及局域网网站和终端等应用。只有三种情况会停下来：

1. **高影响操作**：付款、下单、转账、删除、发送、发布、安装或卸载、丢弃未保存内容、退出应用等，会弹出确认卡，只允许这一次；拒绝后本任务不再尝试同类操作。关闭窗口不算高影响，未保存的内容由 App 自己询问。
2. **账号密码**：代填凭据逐次确认；没有保存的凭据时，Agent 请你自己在目标窗口输入（见[凭据](#凭据)）。
3. **Agent 的提问**：需要你补充信息或做决定时，Agent 在对话里用提问卡片等你回答。

子代理可以执行普通动作，但不能弹出确认卡：它的高影响操作和凭据代填会交回父任务处理。完全放行的 Shell 另有能力执行电脑操作服务以外的命令，因此电脑操作总开关不构成 Shell 的浏览器限制。

**任务结束时释放。** Agent 的回合结束、且它启动的后台子代理都已结束时，这个任务就结束了；停止回合、关闭总开关和删除会话同样结束任务。任务结束时，Agent 控制的所有窗口和标签页都会释放：紫色共享标记和对话预览消失，按住的键和鼠标松开，前台交还给你原来的 App。释放不会关闭任何东西：窗口和应用继续运行，内置浏览器标签页保留页面，已连接的 Chrome 标签页保持连接。下一个任务要重新接手：Agent 会重新列出并绑定窗口，或从标签页列表选回页面；它拿着上一个任务的旧句柄时会得知“已在任务结束时释放”，而不是“窗口已关闭”。某个窗口释放失败时，预览上的卡片会标“释放失败”，Emperor 会断开并重启 Helper 连接，确保录制停止。Agent 用提问卡片等你回答期间，任务不会结束；它若用普通文字提问并结束回合，窗口和标签页会照常释放。

**让 Agent 停下。** 在对话里停止回合，或在“设置 → 电脑操作”关掉总开关（在「能力 › 插件」里停用 Computer Use 插件效果相同）。关掉总开关会取消进行中的动作、撤掉待确认的卡片、让 Helper 松开按住的键和鼠标，并像任务结束一样释放所有窗口和标签页，内置浏览器里 Agent 的页面随之关闭。没有单独的急停快捷键或菜单。

连接、权限或目标过期时，先看设置页各驱动的诊断行和缺失能力，再参考[诊断与排障](diagnostics-troubleshooting.md)。
