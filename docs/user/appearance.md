「设置 › 常规 › 外观」里有主题、皮肤、显示吉祥物、宫廷用语、桌宠的衣服和桌宠六项。它们只改看起来的样子，不影响 Agent 能做什么。

## 主题

「设置 › 常规 › 外观 › 主题」三选一：跟随系统（随 macOS 自动切换）、浅色、深色。侧栏底部的明暗按钮也能切换。

用的皮肤只有一种明暗时（例如「朱批」只有浅色），窗口固定显示它的明暗：这时选深色会提示「皮肤「朱批」只有浅色，换个皮肤才能用深色」，你的选择会记着，换了皮肤后按它显示。

## 皮肤

皮肤只改颜色、标题字体和几张装饰图。对话正文、代码、改动对比、权限确认、费用和登录界面始终保持原来的样子，不会被皮肤改掉。

「设置 › 常规 › 外观 › 皮肤」列出所有皮肤，每张卡片是用它自己的颜色画的小预览，写着作者和「只有浅色」或「浅色和深色」；点「使用」就换上。Emperor 自带三套：

| 皮肤           | 明暗       | 样子                                                                                                                             |
| -------------- | ---------- | -------------------------------------------------------------------------------------------------------------------------------- |
| 御书房（默认） | 浅色和深色 | Emperor 原本的颜色，侧栏底部是穿龙袍的小单                                                                                       |
| 朱批           | 只有浅色   | 宣纸底色和朱砂色，首页问候用宋体，问候上方是朝服小单；你在权限确认卡上允许一个操作后，输入框右上角盖一枚「单」字印，一会儿就消失 |
| 日常           | 浅色和深色 | Emperor 原本的颜色，侧栏底部是日常版小单，空白首页是穿卫衣的小单                                                                 |

- 侧栏底部的小单在侧栏收起或窗口较矮时不显示；首页的插图在和联系人单聊时不显示。
- 选的皮肤记在这台 Mac 上，和主题一样。

### 导入别人做的皮肤

在皮肤页底部点「从文件夹导入…」，选一个含有 `skin.json` 的文件夹。导入前 Emperor 会先检查，通不过时列出全部原因，改好后再导入：

- 文件夹里只能有 `skin.json` 和 PNG、WebP 图片，不能有子文件夹。皮肤不能带脚本、网页、SVG 或样式表，有这类文件的一律拒绝。
- 图片按文件内容判断格式，单张不超过 512 KB，全部合计不超过 4 MB。
- 文字要看得清：正文颜色和背景的对比度不够时拒绝，并写明是哪两个颜色、差多少。
- 皮肤只能改颜色、标题字体和装饰图，不能改字号、间距、出错提示的颜色，也碰不到上面说的那些始终保持原样的地方。

通过检查后，Emperor 把 `skin.json` 和用到的图片复制一份到自己的数据目录，之后原文件夹可以移走或删掉。已经导入过同一个皮肤时，会先问「替换皮肤「…」？」。成功后提示「已导入皮肤「…」」。

- 导入的皮肤可以「删除」，只删 Emperor 里的那一份，不影响你原来的文件夹；官方皮肤不能删除。
- Emperor 每次读皮肤都会重新检查。正在用的皮肤被删除、或者它的文件被改坏时，换回「御书房」并提示，例如「找不到皮肤「宣纸」，已换回「御书房」」。
- 想自己做一套，格式和规则见[皮肤](../design/skins.md)。官方皮肤里的小单只能在 Emperor 里使用，自己做的皮肤请用自己的图片。

## 显示吉祥物

小单是 Emperor 的吉祥物。「设置 › 常规 › 外观 › 显示吉祥物」默认开，关掉后这些地方都不放他的图：

- 第一次用 Build（一个项目都没有）时首页上坐龙椅批奏折的小单，关掉后回到标；
- 皮肤的所有装饰图（侧栏底部、首页的插图和朱批的「单」字印），皮肤的颜色和字体不变；
- 「关于」里的小单；
- 宫廷用语打开时权限确认卡右上角的小贴图。

Emperor 联系人的戴冠头像、「关于」的落款章和桌宠不受这个开关影响：头像在联系人档案里换，桌宠有自己的开关。这个选择只记在这台 Mac 上。

## 宫廷用语

「设置 › 常规 › 外观 › 宫廷用语」默认关。打开后，少数几处换成宫廷说法：

| 位置                 | 平时                                                 | 宫廷用语                                                         |
| -------------------- | ---------------------------------------------------- | ---------------------------------------------------------------- |
| 首页问候             | 今天想聊点什么？/ 今天推进哪个项目？/ 今天找谁帮忙？ | 朕今日要办何事？/ 今日推进哪桩差事？/ 今日宣谁议事？（不带称呼） |
| 权限确认卡的按钮     | 允许本次、拒绝……                                     | 准奏（允许本次）、驳回（拒绝）……                                 |
| 输入框「+」菜单      | 计划模式                                             | 内阁票拟（计划模式）                                             |
| Group 侧栏的新建按钮 | 新建群聊                                             | 召集议事                                                         |
| 权限确认卡右上角     | —                                                    | 小单「嗯？」的小贴图（显示吉祥物关掉时没有）                     |

按钮里始终带着原来的意思，读屏软件读的仍是原话。对话正文、群里成员的发言、代码、费用和出错提示都不变。这个选择只记在这台 Mac 上。

## 桌宠

「设置 › 常规 › 外观 › 桌宠」打开后，小单出现在桌面角落，跟着 Agent 的工作切换动作；默认关闭。窗口出错时，开关下方显示最近的错误。

它上面一行「设置 › 常规 › 外观 › 桌宠的衣服」三选一：

- **日常版**（默认）：黑 T 恤、运动裤；
- **龙袍混搭**：日常衣服外面披一件敞开的金色龙袍，戴一顶歪着的小冠；
- **原版**：0.3 之前的那一套，胸口写着「小单」。

换了马上生效，桌宠正开着也不用重开；关着时，下次打开就穿这一套。

桌宠只显示空闲、工作这类状态，不能代替真实的任务状态，也不能改动 Emperor 里的任何东西。

## 关于

「设置 › 常规」最下面是「关于」：小单、Emperor Agent 和一句「你做决定，agent 们办事。」，落款是「单」字印。「显示吉祥物」关掉时不放小单，落款章还在。

0.3 起 Emperor 的标是一枚冠印：一顶三尖王冠，刻在金色圆角方块上。侧栏、应用图标、安装窗口和首次接入引导用的都是它。
