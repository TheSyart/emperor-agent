Emperor 有三种模式：**Chat**（对话）、**Build**（构建）和 **Group**（群聊）。模式决定侧栏放哪些会话、首页是什么样、⌘N 新建什么；它不改变权限，也不改变 Agent 能做什么。

## 切换模式

侧栏左上角的标志旁写着当前模式：「Emperor Chat ▾」「Emperor Build ▾」或「Emperor Group ▾」。点它（或选中后按 Enter）打开菜单，三种模式各有一句说明：

| 模式  | 说明                                | 快捷键 |
| ----- | ----------------------------------- | ------ |
| Chat  | 对话：提问、写作、调研，不绑项目    | ⌘1     |
| Build | 构建：在项目里写代码、调试和发布    | ⌘2     |
| Group | 群聊：联系人与群聊，多个 agent 协作 | ⌘3     |

- 菜单里用 ↑ / ↓ 移动，Enter 选择，Esc 关闭；点菜单外面也会关闭。
- 切到一种模式时，回到你在这种模式里上次打开的会话；那个会话已经删除、归档，或者已经不属于这种模式，就进这种模式的首页。在当前模式上再按一次它的快捷键，什么都不变。
- 当前模式在重启后保持。
- **别的模式有事**：菜单里每种模式旁写着「N 个在运行」或「等你回答」。只有「等你回答」（有问题要你回答、有操作等你批准）时，标志右上角亮一个橙色小圆点；只是在运行不会打扰你。通知铃铛照旧汇总所有模式的通知。
- 侧栏收起成一列窄图标时，标志下面是三个模式图标，当前模式高亮，点了直接切换；别的模式等你回答时，那个模式的图标上也有小圆点。

## 会话归哪种模式

| 会话                       | 模式  |
| -------------------------- | ----- |
| 和联系人的单聊、群聊       | Group |
| 绑定了项目的会话           | Build |
| 其他会话（没有绑定项目的） | Chat  |

- 按**现在**有没有绑定项目来分：Chat 会话中途绑定了项目，就移到 Build 的那个项目下，当前模式跟着切过去；解绑后回到 Chat。升级到 0.3 时，原来的会话也是这样分的。
- 从通知、搜索结果或链接打开另一种模式的会话时，侧栏先切到那种模式；用后退 / 前进（⌘[ / ⌘]）回到另一种模式的会话也一样。打开设置、定时任务、能力、Pull Request 这些页面不改变模式。
- 侧栏搜索（⌘K）查全部模式：当前模式的结果排在前面，其他模式的结果在「其他模式」下，每一行右侧标着 Chat、Build 或 Group，见[侧栏与会话操作](chat-build.md#侧栏与会话操作)。
- 群成员的工作过程、联系人的试用不出现在任何列表里；搜到群里某位成员说过的话时，结果显示成它所在的群。

## 各模式的侧栏

侧栏一次只显示当前模式的新建按钮和会话：

| 模式  | 新建按钮（⌘N）               | 旁边的 `+` | 会话分组                                |
| ----- | ---------------------------- | ---------- | --------------------------------------- |
| Chat  | 新对话                       | —          | 置顶；今天、昨天、7 天内、30 天内、更早 |
| Build | 新建项目会话（在当前项目里） | 打开文件夹 | 置顶；项目（每个项目下是它的会话）      |
| Group | 新建群聊                     | 新建联系人 | 群聊；联系人                            |

- **⌘N 和新建按钮做同一件事**：
  - Chat：新建一个对话。
  - Build：在当前项目里新建会话。当前项目依次取打开着的 Build 会话的项目、上次 Build 会话的项目、最近更新的项目；一个项目都没有时进 Build 首页，先选项目。
  - Group：打开群聊首页，并弹出「新建群聊」（见[新建群聊](contacts-groups.md#新建群聊)）。⌘3 只回到 Group，不弹出。
- **Chat 的日期分组**：每一天各自可以收起；按手动排序时没有日期，只有一个「对话」分组。排序菜单 `…` 在第一个分组标题旁，指针移上去时出现。一个对话都没有时写「暂无对话」。
- **Build 的项目**：「打开文件夹」直接打开文件夹选择框；在某个项目里新建会话，用项目行上的 `+`。「项目」标题旁的 `+` 照旧有新建空白项目、使用现有文件夹和排序。
- **Group 的两组**：上面是「群聊」，下面是「联系人」，每一行怎么读见[联系人与群聊 › 侧栏](contacts-groups.md#侧栏)。
- **置顶按模式分开**：每种模式只显示自己的置顶，上移、下移也只在本模式的置顶之间换位。某种模式没有置顶时不显示「置顶」标题。
- 删除或归档正在看的会话后，打开同一模式的下一个会话；没有了就进这种模式的首页，不会跳到别的模式。
- 侧栏底部「设置」右边是整页入口图标：定时任务、能力；Pull Request 只在 Build 模式出现（还需要 GitHub 插件启用）。

## 首页

空会话的首页跟着它的模式。三种首页的共同点：

- 还没有可用模型时，输入框下方写明原因：一个模型都没有时给出「开始接入」，有模型但用不了时给出「去处理」。
- 首次接入引导开着时，或者一个模型都没有时，首页不显示起手式和最近的项目，只留接入这一件事。
- 选了带装饰的皮肤时，问候语上方可能有一张小单的插图，见[外观](appearance.md#皮肤)。

### Chat 首页

- 问候是「今天想聊点什么？」；个人档案里写了称呼时带上它，例如「小周，今天想聊点什么？」。
- 输入框下面是 5 个常用起手式：调研一个话题、润色一段文字、翻译、解释一个概念、整理会议记录。点一个只把开头（例如「帮我调研这个话题，列出要点和信息来源：」）接在输入框已有的文字后面，不会发出去。

### Build 首页

- 问候是「今天推进哪个项目？」，下面一行说明构建会话在项目文件夹里运行，可以读写文件、跑命令。
- 输入框底栏 `+` 后面是金色的项目标签和当前分支（不是 Git 仓库时没有分支）。点项目标签可以换成最近的项目（最多 8 个，当前的打勾）或「打开文件夹…」。
- 输入框下面列出最近的 3 个项目和「打开文件夹…」。卡片写着「3 个会话 · 4 天前」，有会话在运行时写「3 个会话 · 1 个在运行」；当前项目的卡片有金色描边。把项目文件夹拖到这一块上，也会换成那个项目；拖进来的是文件时提示「拖进来的不是文件夹，请拖入一个项目文件夹」。
- 换项目不会丢掉你已经输入的文字，项目随第一条消息生效。
- 还没选项目时，项目标签写「选择项目」，发送按钮不可用，提示「先选一个项目」；模型不可用时先显示模型的原因。会话开始后不再有这条限制。
- 一个项目都没有时（第一次用 Build），标的位置换成小单坐龙椅批奏折的插画；窗口较矮时不显示，「设置 › 常规 › 外观 › 显示吉祥物」关掉后回到标。

### Group 首页

- 问候是「今天找谁帮忙？」，下面一行写着：@ 一位联系人就是单聊；@ 几位，会建一个临时群。
- 下面是联系人和最近的群。怎么用见[群聊首页](contacts-groups.md#群聊首页)。

## 快捷键

| 功能                        | 快捷键       |
| --------------------------- | ------------ |
| 切换到 Chat / Build / Group | ⌘1 / ⌘2 / ⌘3 |
| 新建（按当前模式）          | ⌘N           |
| 搜索会话（全部模式）        | ⌘K           |
| 后退 / 前进                 | ⌘[ / ⌘]      |

有弹窗打开时快捷键不生效。其他快捷键见 [Chat 与 Build › 快捷键](chat-build.md#快捷键)。
