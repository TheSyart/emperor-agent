Chat（普通对话）和 Build（项目工作）是会话类型。它们决定 Agent 的工作目录和能看到哪些长期上下文，不决定权限。

## 界面布局

主窗口分三栏：左侧会话栏、中间的对话或整页、右侧工作台。

- 左侧会话栏可以拖动调整宽度，也可以收起为图标栏；窗口宽度小于 1024px 时自动收起，见[侧栏与会话操作](#侧栏与会话操作)。
- 右侧工作台默认关闭，用会话头部右上角的「工作台」按钮或 ⌥⌘B 打开，宽度可在 360–960px 之间拖动。窗口变窄时，工作台先缩窄、再自动收起；窗口重新变宽后恢复原来的宽度。
- 「定时任务」「能力」「Pull Request」「探索」是占满中间和右侧的整页，不显示右侧工作台。
- 侧栏宽度、工作台宽度和当前面板、环境信息卡与「详情」列的开关状态保存在本机界面偏好中，重启后恢复。

## Chat

Chat 适合问答、整理资料、解释内容和不依赖固定项目的轻量任务。上下文包括：

- 系统提示词和当前可用的 Skill 目录；
- 全局工作区说明 `~/.emperor/AGENTS.md`（如存在）；
- 用户档案 `USER.local.md` 与全局长期记忆 `MEMORY.local.md`；
- 当前会话的历史、附件和工具结果。

Chat 的工作目录是 Emperor Home 下的 `workspace/`，Agent 在这里创建的文件不会落到你的项目里。Chat 不会读取任何 Build 项目的私有记忆。

## Build

Build 绑定一个本地文件夹。Agent 在该目录内读取文件、按当前权限写入和执行命令，并装配：

- 从项目根到当前目录逐级发现的 `AGENTS.md`、`CLAUDE.md`、`AGENTS.local.md`、`CLAUDE.local.md`（总预算 64 KiB，越具体的说明优先级越高）；
- `stateRoot/projects/<project-id>/AGENTS.local.md` 中的全局私有项目记忆；
- 项目级 Skills `<project>/.emperor/skills`；
- 当前 Build session 的历史。

项目中的 `AGENTS.md` 等文件由你维护，Core 只读取，不会改写。全局私有项目记忆不在项目源码树中，Agent 可以通过 `memory_edit` 更新它。

## 对话视图

会话头部左侧是路径导航，下方是「对话」「轨迹」两个标签；右上角是「环境信息」（只在「对话」标签显示）和「工作台」两个开关。空白的新对话只显示「工作台」开关。

- **空会话**：输入框居中显示；发送后你的消息以气泡出现，Agent 的回复随即流式输出。
- **思考**：模型的思考过程显示为可折叠的「思考」行，流式输出时只显示最新一行。
- **工具调用**：每次调用占一行，格式为 `图标 标题 · 摘要`。点开后按工具类型展示：终端输出、Diff、读取片段、搜索结果、网页来源、待办清单、已回答的问题、最终 Plan，其他工具显示通用的 IN / OUT。
- **运行状态**：正在进行的 turn 只显示一行状态和已用时间。每个完成的 turn 末尾有复制按钮，悬停可看到首字耗时（TTFT）和 tok/s 等信息。
- 重试、错误、达到最大输出 token、上下文压缩等情况以单独的行插在时间线中。
- **文档链接**：回复里提到的本地文件显示为「类型图标 + 名称」。TS、JS、Vue、Python、Swift、Go、Rust、Shell、HTML、CSS 用语言徽标；文档、PDF、数据与配置、图片、表格、压缩包、目录和网页各有图标。链接文字本身是路径时只显示文件名，悬停显示完整路径。在 Build 会话里点击，项目内的文件在「文件」面板打开（带行号时定位到该行），目录在文件树中展开，项目外的文件在访达中显示；网页链接的打开方式不变。已经不存在的文件显示删除线，点击不会打开；每轮结束后重新检查一次。
- **其他链接**：回复里的链接一律不会让窗口跳转或重新加载。没有扩展名的相对路径（如 `packages/core`）同样交给引用解析，在 Build 会话里打开对应目录；邮件（`mailto:`）和电话（`tel:`）链接交给系统；其他协议不会打开，并提示原因。
- **远程图片**：回复和 Markdown 预览里的网络图片默认不加载，显示为「点击加载图片 · 域名」。点击后由 Emperor 在后台代为下载并显示：不带 Cookie，拒绝本机和内网地址，单张不超过 10 MB；同一张图片在本次运行中再出现时直接显示。

悬停工具行时出现 **Inspect**：点击后切到本会话的「轨迹」标签（`/chat/:id/trajectory?call=<callId>`），选中这次调用，并在轨迹右侧的「详情」列中显示它的参数、结果、工具 Schema 与耗时。调用较早、尚未加载时会先加载更早的记录再定位。

- **变更汇总条**：Build 会话的项目有未提交改动时，输入框上方显示「N 个文件已更改 +A −D」，点击打开右侧工作台的「审查」。它统计的是整个工作区当前的 Git 改动，不是某一轮对话的改动。
- **本轮改动卡**：一轮对话改过文件时，这一轮末尾显示「已编辑 N 个文件 +A −D」，列出每个文件（目录暗色、文件名亮色、增删行数；二进制文件写「二进制」），默认显示前 3 个，点「再显示 N 个文件」展开；标题下方单独显示增删行数，长路径完整换行。统计口径可通过标题旁的信息图标查看。
  - **统计方式**：按这一轮开始和结束时的项目对比，文件工具和终端命令造成的改动都算；同一时间你自己或其他会话对项目的改动也会算进去。只读的一轮没有这张卡。
  - **查看变更**：点「查看变更」或点某个文件，右侧「审查」切到「本轮改动」，只读显示这一轮每个文件的差异；左上角的返回按钮回到平时的审查。
  - **查看文件**：没有 Git 快照的普通会话和非 Git 项目，文件行同样可以点击，打开当前文件的只读预览。Markdown 可切换文档／源码，文本和代码直接显示内容，常见图片显示图片；已移动、删除或不能读取时显示原因。二进制文件只显示类型与大小。
  - **撤销**：点「撤销」会先列出这一轮的文件，可以逐个取消勾选。只恢复这一轮结束后没有再改过的文件，改过的跳过并列出；新建的文件会删除，删除的文件会恢复。撤销后卡片显示「已撤销」，不能重做。Agent 正在这个项目里运行时不能撤销；这一轮期间有其他会话在同一项目运行时，确认框会提示。
  - **限制**：
    - 审核和撤销需要项目在 Git 仓库中；不在 Git 仓库的项目和普通 Chat 只统计 Emperor 文件工具写入的文件，不能审核或撤销。
    - 超过 10 MB 的未跟踪文件只列出，不记录内容，也不能撤销。
    - 大仓库记录一次超过 5 秒时，卡片写「本轮改动未记录」。
    - 每个会话保留最近 50 轮的记录，删除会话时一并清除。
- **轮次刻度**：对话至少有 3 轮、且对话区域不太窄时，左边缘显示一条竖向刻度，每条你的消息一格，当前阅读位置高亮。悬停显示该条消息的前 40 个字，点击或聚焦后用 ↑ / ↓ / Home / End 跳转。刻度只覆盖已加载的对话记录。

### 资源链接与详情

输入框里的网址以网站标记或 GitHub 图标突出显示，仍可逐字编辑、复制和撤销。链接旁不再逐条添加省略号按钮；长名称、网址参数和锚点完整展示，卡片和来源名称自动换行。发送后保留原始网址；代码块和行内代码保持代码显示。Skill 和插件继续使用 `/`、`@` 引用。

回复中的网站链接显示真实图标与完整名称，图标和文字、相邻链接之间保留清楚的留白；常态不显示标签底色。独占一段的单个链接在回复结束后显示摘要卡片，流式输出期间保持正文布局。网页先显示已有标题和域名；GitHub 可区分仓库、PR、Issue、Commit、Release 和 Actions 运行，其他 GitHub 路径显示品牌网页，Enterprise 地址按普通网站显示。

- **打开**：点击链接标题或箭头，沿用浏览器打开偏好。项目文件在右侧「文件」面板打开，`#L12`、`:12`、`:12:3` 可定位行；外部文件在 Finder 中显示。目录使用文件夹图标，缺失文件标为不可用。
- **详情**：点击资源卡片的详情按钮，或环境信息卡中的来源／输出项（键盘 Tab 也可到达），查看完整地址、摘要、状态与出处；PR、Issue、CI 可选择「在 Emperor 查看」。Esc 关闭并返回原来的焦点。
- **图片和附件**：图片详情显示预览，文件附件可在 Finder 中显示。文件类型图标用于识别格式，不代表新增了 Office、音视频等播放器。

正文、资源卡片和来源栏会自动加载可见网站的小图标，同一网站复用缓存；读取失败时才显示域名首字母。图标优先来自网站自身，必要时以公共域名请求 favicon 服务，不携带网页路径、查询参数或登录状态。输入框复用已缓存图标。

网页详情只有主动打开时才补充联网信息；悬停、普通阅读和历史加载不触发网页预览请求。读取不使用浏览器 Cookie，不执行网站脚本；缩略图经后端校验后显示。离线、限流或权限不足时显示原因和重试入口，保留原链接。普通网站继续遵循现有 HTTPS 打开规则，本机地址使用浏览器原有入口。

### 环境信息

「环境信息」卡浮在对话右上角，电脑操作的预览在右下角，两者互不遮挡。

- **展开方式**：对话区域足够宽时卡片默认展开，对话内容和输入框向左让出位置；你用标题栏的「环境信息」按钮或快捷键 ⌥⌘E 关掉后，会一直保持关闭，直到再次打开。较窄时卡片默认不显示，按需打开后覆盖在对话上，按 Esc 或卡片上的关闭按钮收起。
- **标题**：Build 会话的卡片标题是项目名，其他会话是「环境信息」。

Build 会话的第一行是「± 分支名 +A −D」：当前分支、与上游相差的提交数和工作区的增删行数，点击打开「审查」。合并或变基未完成时，下面多一行提示。

标题右侧的「…」菜单包括：

- **打开工作台**；
- **工作位置**：切换回项目目录，或新建、退出、安全删除 Emperor 托管的 worktree；
- **切换分支**：查看并切换分支；
- **提交或推送**：打开「审查」并把焦点放到提交框；
- **比较分支 ↗**：远端 `origin` 是 GitHub 或 GitLab 时，在系统浏览器中打开当前分支与默认分支的比较页；没有 `origin`、远端不是这两者、不在分支上或当前就是默认分支时，这一项不可用并说明原因。

这些写操作与「审查」使用相同的规则：需要确认，Agent 正在运行或 Git 操作尚未完成时不可用。普通 Chat 会话不显示 Git 行，只有一行提示「未绑定项目 · Build 会话可查看变更与分支」，「…」菜单里只有「打开工作台」。

所有会话都会显示：

- **计划**：最近一次 `exit_plan_mode` 的标题和状态（待审阅、已批准、执行中、已完成、继续规划、未批准），执行中时显示待办进度，点击跳到对应的工具行；
- **子智能体**：本会话委派出的子代理，从 36 个小动物、机器人或幻想角色头像中稳定分配形象；同一子智能体在侧栏与委派记录中形象一致，刷新后保持不变。运行中的排在前面，默认显示 3 个，其余点「再显示 n 个」展开，点击打开子会话；
- **后台任务**：有后台命令或工作流运行时显示运行中或已结束的数量。点击展开后每个任务一行，运行中的排在前面，显示状态点、名称、类型或进度（命令的类型或退出码，Ralph 的「第 n 轮」，工作流已启动的代理数）以及已运行时间或结束时间：
  - 「输出」打开只读窗口，命令显示当前保留的输出，工作流显示阶段、日志、代理和结果记录；记录较长时点「加载更多」，任务仍在运行时可「刷新」；
  - 「停止」只对运行中的任务显示。后台命令直接停止；工作流会先确认，因为它正在运行的子代理会一起停止。
- **输出内容**：成功创建的文件、明确生成的附件等有结构化记录的产物，默认显示 3 个，其余可展开。文件修改仍在回合改动卡片里；电脑操作截图属于观察记录。
- **来源**：逐页列出搜索命中、实际读取和正文引用的网页，以及文件、附件、插件、MCP 服务和 Skill。相同资源合并显示，并保留每处使用记录；默认显示 3 个，其余在「查看全部」中。图片和截图显示缩略图，其他文件使用与消息、文件面板一致的类型图标。网页和能力点击查看详情；文件名进入右侧「文件」面板，图片缩略图直接放大；「定位出处」可跳到对应消息或工具行。

计划、输出和来源只根据已加载的对话记录计算；还有较早历史时会提示清单范围，继续加载历史后补齐。当前 Goal 显示在输入框上方的 Goal 条中，卡片不重复显示。

## 轨迹（Trajectory）

「轨迹」标签把同一份会话记录按 Turn → Step 展开成账本，便于逐条核对 Agent 实际做了什么：

- **账本**：每个 Turn 下依次列出用户输入、上下文注入、每次模型请求（Step）的消息、工具调用与结果、压缩；Turn 与工具调用都可以折叠。
- **时间线**：顶部按输入、模型、工具三条泳道显示耗时；拖动选区只看这段时间内的记录，滚轮缩放，右键拖动平移，右键或 Esc 清除。
- **搜索**：工具栏搜索框在全部记录中查找，回车 / Shift+回车在命中之间跳转。
- **详情**：选中一条记录后，账本右侧的「详情」列自动打开并显示它的详情。请求头可看 System Prompt、工具目录和与上一版的 Diff；模型请求可看参数、用量（输入、缓存、输出、推理）和 TTFT / tok/s；工具调用可看参数、结果、调用时的工具 Schema 与耗时；压缩可看摘要和原始输出。
- 「详情」列可以拖动调整宽度（320–720px），也可以用列标题上的收起按钮或工具栏右侧的「详情」开关收起和重新展开；收起不会清除当前选择。没有选中记录时显示「在轨迹中选择一条记录查看详情」。轨迹区域较窄时，「详情」列覆盖在账本上。
- 过大的工具参数或结果在传输时会被截断，「详情」会给出提示，点「加载完整内容」可从本地会话记录读取全文。

## 子代理

子代理的工具行可以点击，在同一视图中打开子会话（`/chat/<childId>`）：

- 头部显示面包屑链（根会话 → … → 当前子会话），点击任一上级即可返回。
- 子会话的输入框是只读的，提供「返回父会话」；子代理仍在运行时可以点「停止」中断它。
- 子代理运行期间，侧栏中父会话行显示「N 个子代理运行中」。子会话本身不会出现在侧栏列表里。

## 右侧工作台

右侧工作台打开时先显示启动器，列出四个面板和各自的[快捷键](#快捷键)；面板标题栏可以在面板之间切换、回到启动器或关闭工作台。

| 面板   | 用途                                                      | 可用条件                 |
| ------ | --------------------------------------------------------- | ------------------------ |
| 审查   | 查看 Diff、暂存、提交、推送、分支、worktree 与当前分支 PR | Build 项目且已初始化 Git |
| 终端   | 在项目目录启动你的系统 Shell                              | Build 项目               |
| 文件   | 只读浏览和预览项目文件                                    | Build 项目               |
| 浏览器 | 在应用内打开网页，包括本机开发服务器                      | 任何会话                 |

不可用的面板在启动器中置灰并说明原因（「当前会话未绑定项目」或「当前项目未初始化 Git」）。再次按同一面板的快捷键会关闭工作台。

- **审查**：按 staged、unstaged、untracked 和 conflict 查看 Diff；执行 stage、unstage、discard、commit、fetch、fast-forward pull、push、建分支、切分支和分支比较；创建或退出 Emperor 托管的 worktree；预览、发布、转 Ready、合并或关闭当前分支 PR。写操作携带 revision，外部改动导致状态过期时拒绝旧操作并刷新。PR 操作依赖通过签名工具目录审核且已登录的 GitHub CLI（`gh`），见[诊断与排障](diagnostics-troubleshooting.md#github-cligh)。
- **终端**：在当前项目目录启动你的系统 Shell，支持多个标签。关闭工作台不结束终端；关闭标签、删除所属 session 或退出应用才会终止，重启后不恢复。终端里还有程序在运行（例如开发服务器）时关闭标签会先确认。
- **文件**：顶部是已打开文件的标签条（「+」新开一个标签），中间是路径和预览，最右侧是项目文件树，树顶部的「筛选文件…」按文件名搜索。支持 Markdown 渲染与源码切换、行号和图片预览；焦点在文件面板内时，⌘W 关闭当前文件标签。`.git` 不展示，目录与搜索都有扫描上限，文件树宽度会被记住。
- **浏览器**：在地址栏输入网址并回车后加载，提供后退、前进、刷新 / 停止、浏览历史和「在外部打开」。设置和限制见下文。

### 浏览器的限制

- 只接受 `http://` 和 `https://` 网址。直接输入 `localhost:5173` 这类本机地址时补全为 `http://`，其他地址补全为 `https://`；带用户名或密码的网址、`file:`、`javascript:`、`data:` 等其他协议都会被拒绝。
- 页面由你打开：在地址栏提交、从浏览历史中选择，或点击界面里的网页链接（按「设置 › 浏览器」的两个打开位置决定在哪里打开）。Agent 和模型输出不能自己打开网页。
- 浏览器使用独立的内存会话：Cookie、缓存和存储不写入磁盘，也不与应用自身的数据共享。切换到其他面板或切换会话时页面关闭，这些数据随之清空；只收起工作台时页面暂时隐藏。
- 网页请求的摄像头、麦克风、通知等权限一律拒绝，弹出窗口不会在应用内打开：外部网址交给系统浏览器，本机地址直接忽略。本机地址也不能用「在外部打开」。
- 下载按「设置 › 浏览器 › 下载」保存（见下文）。可执行文件、安装包和打开时会运行命令的 macOS 文件会被拦截，超过 2 GiB 的文件不会下载；面板底部一行显示正在下载、已下载或已拦截及原因。
- 页面画在界面之上，因此打开弹窗、菜单或拖动分隔条时会暂时隐藏，结束后恢复。

### 浏览器设置与数据

「设置 › 浏览器」管理 Emperor 的内置浏览器：你自己在工作台里浏览，和 Emperor 在对话里操作网页，用的都是它，但两者的数据互不相通。

- **浏览器 · 让 Emperor 控制内置浏览器**（页面顶部）：Emperor 能否在内置浏览器里操作网页。「电脑操作」关着时置灰，旁边的「打开电脑操作」带你过去。
- **常规**：
  - **网页 URL 和链接打开位置**：在会话、Pull Request、GitHub Issue 与 CI、探索等界面中点击的网页链接。默认用系统默认浏览器，沿用那里的登录；选「Emperor」后在右侧「浏览器」面板打开，从 Pull Request 等整页界面点击时会先回到当前会话。
  - **本地 URL 打开位置**：localhost 等本机开发站点，默认在「Emperor」里打开。改成系统默认浏览器后，本机地址会带着你系统浏览器里的登录打开。
  - **显示完整网址**：关闭后地址栏平时只显示网站名，点击编辑时显示完整网址。
  - **浏览数据**：「清除浏览数据」关闭当前页面，清除内置浏览器的 Cookie、网站数据、缓存、登录凭据、浏览历史和你的下载记录。完成后这一行显示「已清除」；失败时显示「清除失败」，原因写在这一行的说明里。已下载的文件和 Emperor 的登录状态不受影响。
  - **浏览历史**：记录你打开过的网页（地址、标题、时间），点浏览器工具栏的历史按钮可以再次打开。只在内存里，切换会话、清除数据或退出应用后都不保留；关闭这个开关会同时清空已有记录。
- **自动填充和密码**：「密码管理器」和「登录状态」都在「管理」后面的二级页，用于 Emperor 操作网页，见[电脑操作](computer-use.md#凭据)。
  - **导入…**（「自动填充和密码」标题右侧）：从本机的 Chrome 或 Edge 导入。选择来源浏览器和个人资料，勾选要导入的数据：「已保存的密码」进密码管理器，「Cookie（登录状态）」进你选定的持久登录状态 profile（默认第一个，没有就新建「从 Chrome 导入」/「从 Edge 导入」）。**导入前请完全关闭那个浏览器**，检测到它还开着时「导入」会置灰，可以「重新检查」。读取和解密都在本机完成，读取密码时 **macOS 会弹出钥匙串授权框**，请点允许；只导入密码与登录，**不导入浏览记录**，也没有扩展程序。完成后告诉你导入了多少个密码、多少个网站的登录；密码管理器上锁时会先提示你去解锁。同一网站同一用户名已有的密码不会重复导入。
- **下载**：前三项管你自己在内置浏览器里的下载。
  - **位置**：下载的文件直接存到这里，默认是系统下载文件夹。「更改」在系统对话框中选一个文件夹，改过之后可以「恢复默认」；选的文件夹不在了，就存回系统下载文件夹。同名文件自动加序号，例如 `report (1).csv`。
  - **下载前询问保存位置**：打开后每次下载先弹出系统的保存对话框，从「位置」开始，可以改名字和文件夹。
  - **下载历史记录**：「管理」后的二级页分两组。「你的下载」可以打开、在访达中显示或从列表移除（文件保留），被拦截的写明原因；「Emperor 的下载」列出收件箱中的文件，可以在访达中显示、移到工作区或另存为。
  - **下载保留时间**：Emperor 下载的文件在收件箱中保留的时间。
  - 沿用 Emperor 收件箱的检查：可执行文件、安装包，以及打开时会运行命令或启动本机应用的 macOS 文件（如 `.terminal`、`.fileloc`、`.webloc`、AppleScript）一律拦截，在保存对话框里改成这类名字的也一样，已经写出的会被删除。单个文件最大 2 GiB，事先知道大小的不开始下载，下载中超过的立即停止。在 macOS 上，下载好的文件带系统的隔离标记，第一次打开时由系统检查。
  - 下载记录保存在 `~/.emperor/browser/user-downloads.json`（只有你能读写），只有名称、来源网站、保存位置、时间、状态和大小，不含下载地址，最多保留最近 200 条。
- **浏览器权限**：「网站设置」管理 Emperor 操作的网页可以用哪些摄像头、麦克风、位置、通知等权限。

二级页的页头是「浏览器 › 页面名」，点「浏览器」回到主页。主页和二级页上的操作失败时，页面顶部出现一张提醒卡写明原因，没有问题时不显示。

## Pull Request

侧栏的「Pull Request」打开一个全局的 PR 浏览页，不绑定会话或项目。它通过本机的 GitHub CLI（`gh`）读取与当前 GitHub 账户相关的打开状态 PR：

- 顶部三个标签：「全部」（与你相关）、「正在审查」（请求你审查）、「由我创建」。可以按文本搜索，也可以在筛选菜单中只看草稿、检查失败或需要修改的 PR，并按仓库分组。一次最多加载 50 个，超出时列表底部说明总数。
- 选中一个 PR 后，右侧显示标题、状态、分支、作者、增删行、文件数、提交数和审查结论，以及「概览」（描述、检查结果、改动文件）和「查看 diff」两个标签；「在 GitHub 打开」在系统浏览器中打开原页面。Diff 过大时只显示开头部分。
- PR 地址会写入页面路径（`/pulls/<owner>/<repo>/<number>`），后退 / 前进可以在看过的 PR 之间切换。
- 这个页面只读，不能合并、关闭或检出 PR；当前分支 PR 的发布、合并和关闭在右侧工作台的「审查」中完成。

`gh` 未安装、版本过低或未登录时，页面显示对应的说明和「重新检测」按钮，处理方法见[诊断与排障](diagnostics-troubleshooting.md#github-cligh)。

### Issue 与 CI（GitHub 插件）

自带的 GitHub 插件启用时（默认启用，见[插件](tools-skills-mcp.md)），这个页面的标题变为「GitHub」，标题下多出「Pull Request」「Issue」「CI」三个标签。三个标签都只读，都通过同一个 `gh` 读取：

- **Issue**：列出打开状态的 Issue，分「与我相关」（你创建、被分配、被提到或评论过）、「我的仓库」（你名下仓库里的 Issue，包括别人开的）、「分配给我」「我创建的」「提到我」，可以按文本搜索；上次选的分类会记住。点开一个 Issue 在原处显示状态、标签、负责人、描述和最近 30 条评论，「在 GitHub 打开」查看其余内容。路径为 `/github/issues/<owner>/<repo>/<number>`。
- **CI**：列出一个仓库最近 30 次 GitHub Actions 运行。仓库默认取当前项目的 GitHub `origin`，也可以输入 `owner/name` 后按「查看」。点开一次运行显示各个作业及其步骤的结果和用时；日志在 GitHub 上查看（「日志」按钮）。路径为 `/github/ci/<owner>/<repo>/<运行 ID>`。仓库没有运行记录或没有启用 Actions 时显示「没有运行记录」。
- 标题和描述都按文字显示，描述中的 HTML 不会执行；描述中的网页链接按「设置 › 浏览器」的打开位置处理，「在 GitHub 打开」始终交给系统浏览器。

插件还带一个 GitHub Skill，让 Agent 在终端里用 `gh` 做同样的只读查询。在「能力 › 插件」里停用 GitHub 插件后，这两个标签和 Skill 一起撤下，页面恢复为「Pull Request」，已登录的 `gh` 不受影响；直接打开 `/github/…` 地址时，页面说明插件已停用并给出打开插件的按钮。

## 斜杠命令

Composer 输入 `/` 后显示 Core 返回的命令和 active Skill，分为 `Commands` 与 `Skills`：

- `/new`：在同一工作区创建新会话；旧会话保留在侧栏。新会话继承 Chat/Build 类型、项目、活动 worktree 和当前权限预设，不继承对话、Plan 模式、Goal 或排队消息。
- `/compact`：在当前会话中压缩历史并保留摘要。
- `/model`、`/reasoning`：选择模型和思考强度。
- `/permissions`：查看或切换权限预设。
- `/plan`、`/goal`：进入 Plan 模式或设置 Goal，见 [Plan 与 Goal](plan-goal.md)。
- `/stop`：停止当前任务；`/continue`：让 Agent 继续上一项工作。
- 每个 Skill 使用自己的命令，例如 `/agent-reach 搜索相关讨论`。

输入框里以 `/` 开头、但不是任何命令或 Skill 的词（例如 `/tmp 下有什么`）会在输入时提示「不是命令，将作为普通消息发送」，回车后作为普通消息发出；命令列表还没加载完时，最多等 2 秒再判断。模型回复中的斜杠文本不会执行。只有 Skill 命令可以携带附件。完整规则见 [Slash command 平台](../architecture/slash-command-platform.md)。

### 在消息里引用技能和插件

在消息中间（空格之后）输入 `/` 时只列出 Skill；`a/b`、网址和路径里的 `/` 不会弹出列表，输入空格或按 Esc 即关闭。选中的 Skill 在输入框里变成带图标的芯片，发送时模型收到 `/Skill 名`，Agent 随即载入该 Skill 的说明。

在消息开头或空格之后输入 `@` 时只列出插件，按名称、ID 和说明筛选，可用的排在前面。停用、来源未验证或不能使用的插件灰显并写明原因（例如 Computer Use 显示「电脑操作未开启」），选中它会打开插件详情，不会插入芯片。选中可用的插件后，输入框里是带插件 Logo 的芯片（没有 Logo 时用首字母色块），发送时模型收到 `@插件 ID`，同时收到这个插件的说明：它有哪些 Skill、MCP、应用连接和 Hook，各自能否使用（例如 GitHub 的 `gh` 是否已登录），以及插件 Skill 的说明（内容较多时只给出目录，由 Agent 按需载入）。插件未启用或不存在时，模型只会得到一句说明，并如实告诉你，不会假装用了它；Computer Use 关闭时模型会提醒你在「设置 › 电脑操作」里打开，不会自己打开。这些说明作为会话中的一条上下文消息加入，不改动系统提示。

也可以用下面几种方式得到芯片：

- 完整输入已有的 `/Skill 名` 或可用插件的 `@插件 ID` 后按空格；
- 从「+」菜单的「插入 Skill 或插件」在光标处插入；
- 粘贴包含 `/Skill 名`、`@插件 ID` 的文字，已有的名字会还原成芯片，没有的名字保持文字。

芯片是一个整体：光标跳过它，退格整体删除，撤销可以找回。复制时得到 `/Skill 名` 或 `@插件 ID` 文字。消息开头的 Skill 芯片与 `/Skill 名 参数` 命令相同。发送后的消息气泡和排队中的消息同样显示芯片；Skill 或插件后来被删除或停用时，芯片变灰并标「已不可用」。点「编辑后重新发送」时，芯片原样回到输入框。

## 语音听写

在 macOS 上，输入框发送键左侧有一个麦克风。点它，或在输入框里按 ⇧⌘D，开始听写。听写时，输入框底部一行换成录音条：

- 左边的 × 取消听写，这段话不放进输入框。
- 中间的波形随麦克风的音量起伏，最新的在最右边，安静时是一排点，显示大约最近 3 秒。系统开启「减少动态效果」时波形不滚动，只在右端显示当前音量。
- ■ 停止听写，文字放进输入框，不发送；在输入框里再按一次 ⇧⌘D 也一样。指针停在 ■ 上会显示快捷键。
- 最右边的发送键结束听写，等最终文字放进输入框后，连同输入框里原有的内容一起发送；没有得到最终文字（例如识别失败）时不发送。

说话时，识别出的文字以浅色虚线显示在开始听写的位置，还没有进入输入框；输入框为空时，占位提示让给这段文字。你可以同时继续打字，听写的位置会跟着移动。

- 结束后，最终文字一次性放到开始时光标所在的位置；开始时选中了文字，就替换选中的部分。整段文字一步就能撤销，已有的技能和插件芯片不受影响。除非你按录音条上的发送键，听写不会发送消息。
- 听写时切到别的对话，录音立即停止，这段文字不会写进别的对话。回到原来的对话时，输入框上方会提示「听写结果还没放进输入框」，可以插入或丢弃。这个提示只保留到关闭 Emperor。

识别全部在这台 Mac 上完成：声音只在内存中处理，结束后即丢弃；识别出的文字只有你放进输入框的部分才会出现在对话里，不另外保存。当前语言没有本机识别模型时，听写直接失败并说明原因，不会改用云端识别。

第一次听写时，macOS 会请求「麦克风」和「语音识别」两项权限。「设置 › 语音」先放「听写」卡片里的三项选择，系统权限放在最后：

- 麦克风。选定的麦克风断开时，听写先用系统默认的麦克风，重新连接后自动恢复。
- 识别语言。只列出这台 Mac 能在本机识别的语言，「跟随系统」会显示实际使用哪一种；要识别更多语言，到「系统设置 › 键盘 › 听写」添加。
- 快捷键。不能与 Emperor 自己的快捷键或 macOS 保留的组合相同。
- 系统权限。两项状态相同时合成一行，例如「麦克风和语音识别 · 已允许」；不同时各占一行。

权限被拒绝或受管理设置限制、听写组件（Emperor Dictation Helper）不可用时，页面最上面出现一张提醒卡，写明原因和怎么修：被拒绝的权限点「打开系统设置」直达对应的隐私列表，打不开时提醒卡写明手动前往的位置；听写组件点「重新检测」，右上角的刷新也一样。一切正常时不显示提醒卡。

Windows 和 Linux 暂不支持听写。

## 侧栏与会话操作

左侧会话栏从上到下是：

- 收起按钮与后退 / 前进；
- Emperor 标志与名称（只展示）、搜索和通知铃铛；
- 「新对话」和它右侧的 `+`（在已有项目中新建会话，或「选择项目文件夹…」新建 Build），以及「Pull Request」「定时任务」「能力」「探索」四个整页入口；
- 「置顶」「项目」「对话」三组会话：「项目」按项目列出 Build 会话，「对话」按日期列出 Chat 会话；
- 底部的「设置」和明暗切换按钮；收起后的窄轨同样保留这两个按钮。

收起后的图标栏保留展开、后退 / 前进、新对话、搜索、通知、四个整页入口和设置。窗口宽度小于 1024px 时会话栏自动收起为图标栏。

悬停会话行后点击 `…` 可以重命名、置顶或取消置顶、归档和删除（双击标题也可以重命名）；手动排序时还可以上移、下移。运行中的会话会显示运行状态，以及「N 个子代理运行中」。

- **置顶**：置顶的会话出现在「置顶」组的最上方，不再在「项目」或「对话」中重复出现；置顶组内可以上移、下移。最多置顶 50 个会话。归档或删除会话时自动取消置顶。
- **搜索**：点击搜索图标或按 ⌘K，按标题或项目名称、路径搜索未归档的会话。
- **后退 / 前进**：在应用内的页面和会话之间后退或前进（⌘[ / ⌘]）。
- 归档会话从主列表移除，可以在“设置 → 常规 → 已归档对话”恢复。
- 删除会话会停止它的后台任务并把它移到“设置 → 常规 → 最近删除”：删除后提示条上的「撤销」在 10 秒内可以把它原样放回；之后也可以在最近删除里恢复。最近删除里的会话保留 30 天后自动清除，也可以在那里「永久删除」（需要确认），这时对话记录、附件和回合快照才真正删除。
- 归档、重命名或删除失败时会弹出说明原因的提示，会话保持原样（不取消置顶、不跳转）。
- 切换会话不会把进行中的后台 turn 转移到新会话。
- 新建会话时界面先创建本地草稿，发送第一条消息后才创建真实会话；首条消息之后会自动生成标题。

### 通知

通知铃铛在有未读通知时显示小红点，点开后可以「全部已读」或「清空」。通知来自：

- 定时任务运行完成或失败；
- 其他会话中等待你回答的问题、审批或待确认的计划；
- 不在屏幕上的会话完成了一轮回复；
- 通过「审查」或环境信息卡完成的 Git 操作（提交、推送、切换分支、worktree、发布或合并 PR 等）。

窗口在前台时，你正在查看的会话里的问题和回复不会产生通知。点击通知会跳到对应会话、定时任务页，或打开该会话的「审查」。通知只在应用内显示，不发送系统通知；列表最多保留 50 条，保存在本机界面偏好中。

## 运行中继续发送

Agent 正在回复时仍可输入文字、添加附件和引用 Skill：

- **发送**：消息排队，当前 turn 结束后作为下一轮开始。排队的消息显示在 Composer 顶部，不会提前出现在聊天时间线中。
- **插入当前执行**：把排队的消息提升为插话，在下一个 step 进入当前 turn。
- **删除**：取消尚未开始的排队消息。
- **停止**：取消当前 turn；排队的消息不会被删除，也不会自动接着运行，显示为「待发送 · 上一轮已停止」。
- **待发送**：当前 turn 出错或被成本上限等拦下时，排在后面的消息不会自动运行，显示为「待发送 · 上一轮失败」；应用在消息发出前退出或崩溃，重新打开会话后显示为「待发送 · 应用重启前未发出」。点「发送」让它像新消息一样运行，点「丢弃」删除它，也可以编辑后重新发送。待发送的消息不会挡住你直接发送新消息。

审批、问题（支持多选）和 Plan 审阅出现时，会以卡片形式在底部接管 Composer 的位置；回答、批准、提交意见或取消后，Composer 连同原草稿恢复。按 Esc 只会把卡片收成输入框上方的一行（「等待你回答」等），点「展开」回到卡片；取消必须点卡片上的按钮。输入法组字时按 Esc 不会影响卡片。

### 草稿不会丢

- 发送被拒绝（例如队列已满、会话正在切换、模型不可用）时，原文、Skill 芯片和附件都会放回输入框；如果期间你又输入了内容，退回的消息接在后面。
- 每个会话有自己的草稿：切到别的会话再切回来，未发送的文字、芯片和已上传的附件还在。草稿只保存在当前窗口，重新加载后清空。
- 附件上传完成前不能发送，发送按钮暂时不可用。可以直接粘贴截图或复制的文件，它们会成为附件。
- 编辑排队消息或历史消息时，如果输入框里已有内容，原内容保留，被编辑的消息接在后面；排队消息的附件和芯片一起回来。
- 消息里像是 API Key、令牌或私钥时，发送前会提示：可以「遮掩后发送」（替换为 `[已遮掩]`）、「仍然发送」或取消。

复杂任务不会因为固定的步数上限突然停止：内核不限制一个 turn 的步数。连续重复完全相同的工具调用时，Agent 会收到提醒。

## 权限和路径

Build 绑定目录并不意味着 Agent 可以任意写整台机器：

- 权限预设决定写入范围。默认的 `workspace-write` 只允许写入当前 workspace 和系统临时目录；`read-only` 不允许写入；`danger-full-access` 不限制。
- 超出范围时，Agent 可以为单次调用请求提权，由你批准或拒绝，批准只对这一次调用有效。
- `read`、`glob`、`grep` 可以读取工作区之外的文件；沙箱不限制网络访问。
- Shell 命令在 macOS 和 Linux 上由系统沙箱执行；其他平台只有 `danger-full-access` 才能运行 Shell。

右侧工作台的「终端」是你直接操作的 Shell，不属于 Agent 工具调用，不受权限预设约束，也不进入聊天记录或模型上下文。

## 什么时候切换类型

| 任务                           | 建议                         |
| ------------------------------ | ---------------------------- |
| 普通问答、总结一段文本         | Chat                         |
| 修改一个明确项目中的代码或文档 | Build                        |
| 同时维护两个项目               | 为每个项目建立独立 Build     |
| 需要先审查实施方案             | 在 Chat 或 Build 中进入 Plan |
| 需要 Agent 持续推进直到完成    | 在合适的会话中设置 Goal      |

Plan 和 Goal 见 [Plan 与 Goal](plan-goal.md)。数据隔离细节见[全局私有存储根](../architecture/global-state-store.md)。

### 查看文件与放大图片

对话正文、附件、输出清单和「已编辑文件」中的文件名都在右侧「文件」面板打开当前内容；「查看变更」仍用于查看差异。普通聊天也能使用文件面板。支持多标签、刷新、Markdown／源码切换及代码行号；不支持的格式显示文件信息，外部文件可在 Finder 中定位。文件名完整显示，面板不会修改文件。

发送前后的图片附件只展示缩略图，不显示名称、大小或类型；待发送图片保留移除按钮。点击缩略图直接放大。灯箱支持滚动缩放、拖动、适应窗口、原始大小、旋转和同组图片切换；按 Esc 或点击空白遮罩退出，点「在文件中查看」进入文件面板。来源等清单中的图片文件名仍进入文件面板。Computer Use 放大的是已收到的画面，不会因此再操作电脑。
