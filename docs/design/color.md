# 颜色使用规范

> 文档状态：Active<br>
> 面向读者：设计者、前端开发者<br>
> 最后核验：2026-10-25<br>
> 事实源：`desktop/src/renderer/src/theme/`（`primitives.css`、`semantic.dark.css`、`semantic.light.css`、`components.css`、`tokens.test.ts`）、`styles/a11y.css`、`components/ui/`（`Badge.vue`、`Notice.vue`、`Button.vue`、`Dot.vue`）、`desktop/src/main/window-background.ts`、[设计令牌](tokens.md)

方向是高级、简约、克制：界面以暖中性灰为主，层级靠表面明度和 0.5px 细线区分，不靠大面积色块。Emperor 金保留，但只出现在少数关键位置。深色是默认主题，浅色与它一一对应（两套 L2 的键集合相同，`tokens.test.ts` 守护）。

## 表面

四档明度从窗口底色往上叠：canvas → base → raised → overlay。

| 令牌                 | 深色      | 浅色      | 用在哪                                   |
| -------------------- | --------- | --------- | ---------------------------------------- |
| `--surface-canvas`   | `#141413` | `#F6F5F2` | 窗口底色、侧栏、设置导航、工作台页签条   |
| `--surface-base`     | `#1A1A19` | `#FFFFFF` | 中栏与工作台的面板                       |
| `--surface-raised`   | `#212120` | `#F7F6F3` | 面板里抬起的填充：卡片、输入框、代码块   |
| `--surface-overlay`  | `#282826` | `#FFFFFF` | 菜单、弹层、输入控件底色                 |
| `--surface-sunken`   | `#141413` | `#F6F5F2` | 凹下去的区域                             |
| `--surface-selected` | `#30302E` | `#E7E5E0` | 选中的行                                 |
| `--surface-hover`    | 白色 5%   | 暖黑 4.5% | 悬停叠层（半透明，叠在任何表面上都成立） |
| `--surface-active`   | 白色 8%   | 暖黑 8%   | 按下叠层                                 |

- 浅色主题四层表面（canvas、base、raised、selected）互不相同（`tokens.test.ts`）。浅色的 overlay 与 base 同为白色，靠阴影分层。
- 主窗口在页面绘制之前的底色取 `--surface-canvas`，跟随系统外观，启动时不闪色（`window-background.ts`）。
- 分隔用 0.5px 的 `--hairline`（深色白 10%，浅色黑 12%），画成 `box-shadow`，或者直接靠表面色差，不画 1px 实线（样式审计的 ratchet 规则，计数只降不升）。
- 层级阴影：深色 `--elev-1..3` 加重了投影并带 0.5px 白色细边，暗底上也看得见；浅色是 0.5px 黑边加柔和投影。卡片 `--elev-1`、弹层 `--elev-2`、对话框 `--elev-3`；遮罩 `--scrim`（深色黑 55%，浅色黑 24%）。

## 文字

| 令牌                  | 深色      | 浅色      | 用途                       |
| --------------------- | --------- | --------- | -------------------------- |
| `--text-1`            | `#ECECEA` | `#1C1B19` | 主文字                     |
| `--text-2`            | `#A8A6A1` | `#5F5D58` | 次要文字、说明             |
| `--text-3`            | `#8A8780` | `#75736D` | 元信息、分组标签、时间     |
| `--text-4`            | `#52514D` | `#B3B1AB` | 只给占位符与禁用文字       |
| `--text-link`         | `#DDB878` | `#8E6420` | 链接与行内引用             |
| `--text-accent-muted` | `#C5A975` | `#7E6234` | 设置左栏的分组标题（淡金） |

文字层级用这四个实色，不用透明度叠出来。实测对比度（WCAG 2.x，前景对背景）：

| 前景                  | 深色 canvas | base  | raised | overlay | selected | 浅色 canvas | base  | raised | overlay | selected |
| --------------------- | ----------- | ----- | ------ | ------- | -------- | ----------- | ----- | ------ | ------- | -------- |
| `--text-1`            | 15.58       | 14.72 | 13.62  | 12.49   | 11.18    | 15.79       | 17.21 | 15.92  | 17.21   | 13.67    |
| `--text-2`            | 7.58        | 7.16  | 6.63   | 6.07    | 5.44     | 6.03        | 6.58  | 6.09   | 6.58    | 5.22     |
| `--text-3`            | 5.14        | 4.86  | 4.50   | 4.12    | 3.69     | 4.35        | 4.74  | 4.39   | 4.74    | 3.77     |
| `--text-4`            | 2.32        | 2.19  | 2.03   | 1.86    | 1.66     | 1.97        | 2.14  | 1.98   | 2.14    | 1.70     |
| `--text-link`         | 9.83        | 9.29  | 8.60   | 7.88    | 7.05     | 4.82        | 5.26  | 4.87   | 5.26    | 4.18     |
| `--text-accent-muted` | 8.17        | 7.72  | 7.14   | 6.55    | 5.86     | 5.23        | 5.70  | 5.27   | 5.70    | 4.53     |

- `tokens.test.ts` 保证：`--text-1`、`--text-2` 在 base 和 raised 上 ≥ 4.5:1；`--text-3` 在 base 上 ≥ 4.5:1，在 raised 上 ≥ 4.3:1（记录在案的例外，浅色 4.39）；链接在 base 上 ≥ 4.5:1；`--text-accent-muted` 在 canvas 上 ≥ 4.5:1。
- 浅色主题的 `--text-3` 在 canvas 上只有 4.35:1（侧栏的时间与计数就在这里），选中行上的 `--text-3` 两套主题都不到 4.5:1：选中行里的元信息不要再降到 `--text-4`。
- `--text-4` 达不到正文对比度，只给占位符与禁用状态，不承载需要读的信息。
- 强调色填充上的文字用 `--text-on-accent`（深色 8.46:1，浅色 4.46:1）。

## 金色（`--accent`、`--text-link`、`--focus-ring`）只用于

- 发送按钮，以及每屏唯一的主按钮；
- 选中的开关；
- 链接与行内引用；
- 焦点环；
- 品牌标；
- 唯一的「运行中」指示。
- 设置左栏的分组标题「智能 / 操控 / 系统」：用淡金 `--text-accent-muted`（金色与 `--text-2` 调和，深色约 65% 金），13px 半粗；它只是标题，不可点击，其他标签和元信息仍用 `--text-3`。

不用金色的地方：tab 选中改用 `--text-1` 加 500 字重；侧栏选中行用 `--surface-selected`；审批卡和计划卡用 `--attention`（橙），不用金色；徽章、图表和装饰不用金色。

- `Button` 的 primary 是 `--accent` 填充、`--text-on-accent` 文字，同一个容器里出现第二个时开发态会警告。其余按钮用 secondary（`--surface-active` 填充）或 ghost。L3 的 `--button-primary-fill`（反色填充）目前只用在启动失败页的「重试」上。
- 焦点环统一画成两层阴影：先是 2px 的面板底色，再是 4px 的金色 55%（`0 0 0 2px rgb(var(--surface-base)), 0 0 0 4px rgb(var(--focus-ring) / 0.55)`），浅色背景和深色背景上都能看清。
- 深色的金色 `#D4AA5E`、链接 `#DDB878`；浅色的金色 `#9C6F24`、链接 `#8E6420`，深一档以保证白底上的对比度。

## 状态色

| 令牌          | 含义                       | 深色      | 浅色      |
| ------------- | -------------------------- | --------- | --------- |
| `--ok`        | 成功、已连接               | `#4CC38A` | `#1F9D55` |
| `--warn`      | 警告、需要注意但不阻塞     | `#E8A23B` | `#B5600B` |
| `--error`     | 错误、破坏性操作           | `#F07070` | `#D93030` |
| `--attention` | 等待用户的审批、授权与计划 | `#F0883E` | `#C2570C` |
| `--info`      | 中性的说明与提示           | `#7AA7F7` | `#2F6FE0` |

- 状态色只表达状态，配套的 `*-soft` 用作底色。状态色不做装饰，也不用于普通按钮。
- 浅色主题的状态色直接放在 soft 底色上对比度不够（成功 3.12:1、警告 3.98:1），所以 Badge 与 Notice 在 soft 底上的文字用 L3 的 `--state-ok-label`、`--state-warn-label`、`--state-error-label`（浅色 4.94、5.45、5.61:1）；图标与圆点仍用状态色本身。
- `--attention` 专门表示「等你处理」：审批卡、授权卡、计划卡、侧栏里等待回答的橙点、工具树里待审批的图标。它和 `--warn` 不混用。
- 危险操作的悬停底色是 `--surface-hover-danger`；危险按钮（`Button` 的 danger）只在确认场景出现。

## 用户气泡

用户消息气泡用 `--bubble-user`：深色主题是暖深灰 `#2B2720`，浅色主题是暖米色 `#F7EFE0`，都不是金色；气泡里的文字是 `--text-1`（12.56:1 / 15.06:1）。

## 组件专用色（L3）

不在 L2 语义里、只属于某类组件的颜色在 `components.css`，深浅各一套：

- 代码高亮 `--code-*`（关键字、字符串、函数、常量、注释、标点、链接），代码块底色 `--code-block-bg`、行内代码底色 `--inline-code-bg`；
- 头像色 `--avatar-1..6`（`Avatar` 的 color 类型按 id 或名字固定取其一）；
- 提示气泡 `--tooltip-bg`/`--tooltip-fg` 与轻提示 `--toast-bg`/`--toast-fg`：两套主题都是反色块（深色主题是浅底深字）；
- 侧栏、菜单、设置卡片、输入框、环境信息卡的填充色，都指回 L2 表面。

站点图标下的白底 `--site-icon-plate` 与电脑操作截图上的指针 `--pointer-ink` 两套主题相同；看图器始终是深色观看面（`base.css` 的 `--image-viewer-*`）。

## 系统偏好

`styles/a11y.css` 集中处理：

- **增强对比度**：加深不透明边框 `--stroke-solid` 与 `--stroke-solid-strong`。
- **减少透明度**：两档背景模糊归零，看图底色的不透明度升到 0.98。
- 减少动态效果见[动效](motion.md)。
