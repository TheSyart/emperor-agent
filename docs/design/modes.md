# 三种模式

> 文档状态：Active<br>
> 面向读者：设计者、前端开发者、维护者<br>
> 最后核验：2026-10-27（对照 `b28fc6e6`）<br>
> 事实源：本文是 0.3 的设计稿，已实现的部分以 `desktop/src/renderer/src/runtime/appMode.ts`、`desktop/src/renderer/src/components/sidebar/`（`ModeSwitcher.vue`、`modeEntries.ts`、`SidebarRoot.vue`、`SidebarNav.vue`、`SidebarFooter.vue`、`SidebarRail.vue`）、`packages/core/src/api/core-api.ts`（侧栏状态的 `app_mode`、`mode_routes`）和 `desktop/tests/visual/sidebar.spec.ts` 为准

Emperor 有三种模式：**Chat**（对话）、**Build**（构建）、**Group**（群聊）。模式是界面层的概念，决定侧栏放什么、首页长什么样、⌘N 新建什么；会话本身仍然只有 `mode: chat | build`，群聊相关的会话用 `surface` 字段标记。

## 切换

- 侧栏左上角的品牌行就是切换器：标 +「Emperor Chat ▾」「Emperor Build ▾」「Emperor Group ▾」。完整名就是按钮的 `aria-label`。侧栏窄于 248px 时只显示模式名（「Build ▾」），完整名放在 tooltip 里；侧栏现在最窄 264px（`columns.ts`），所以这条只在以后放宽下限时才会用到。
- 点开是一个菜单（`ui/Menu`，宽 340），三项各有图标、名字（Chat / Build / Group）、一句中文说明（对话：提问、写作、调研，不绑项目；构建：在项目里写代码、调试和发布；群聊：联系人与群聊，多个 agent 协作）、快捷键和勾；每一行都给勾留位，快捷键列对齐。
- 快捷键：⌘1 Chat、⌘2 Build、⌘3 Group。
- 键盘：Enter / Space（或 ↓）打开，焦点落在当前模式上；↑↓ 循环移动，Home / End 到头尾；Enter 选择；Esc 关闭并把焦点还给按钮；点菜单外面也关闭。菜单项是 `menuitemradio`，`aria-checked` 为 true / false。
- 当前模式记在侧栏状态里（`app_mode`），重启后保持；每种模式记住上次打开的会话（`mode_routes`，不记草稿）。切换时回到上次的会话，会话不在了就回到这种模式的首页。

## 会话归哪种模式

| 会话                                                          | 模式             |
| ------------------------------------------------------------- | ---------------- |
| `surface` 是 `contact`（单聊）或 `group`（群）                | Group            |
| 绑定了项目（`project_path` 非空）                             | Build            |
| 其余                                                          | Chat             |
| `surface` 是 `group_member`（群成员会话）或 `trial`（试用台） | 不出现在任何列表 |

- 按**现在是否绑定项目**来分：Chat 会话中途绑了项目，就移到 Build 的那个项目下；解绑就回到 Chat。会话的 `mode` 字段不迁移。
- 不变量：当前打开的会话所属的模式就是 `app_mode`。从通知、搜索、深链、前进后退打开别的模式的会话时，先切模式。设置、定时任务、能力、Pull Request 这些页面不属于任何模式，打开它们不改 `app_mode`。

## 侧栏

| 模式  | 主按钮（⌘N）                                  | 分区                                                                          |
| ----- | --------------------------------------------- | ----------------------------------------------------------------------------- |
| Chat  | 新对话                                        | 置顶（只含 Chat 会话）、对话（今天、昨天、7 天内、30 天内、更早）             |
| Build | 新建项目会话（当前项目），旁边「+」打开文件夹 | 置顶（只含 Build 会话）、项目 → 会话（可折叠）                                |
| Group | 新建群聊，旁边「+」新建联系人                 | 群聊、联系人（GRP-05 接入之前是一行占位：「联系人和群聊在这里」，没有假数据） |

- 同一时刻侧栏只渲染一种模式的分区。某种模式没有置顶时，不显示「置顶」标题；置顶的上移、下移只在本模式的置顶之间换位，别的模式的置顶顺序不动。
- 主按钮和 ⌘N 走同一段代码（App 里的模式控制器，经 app context 交给侧栏），所以永远一致；窄轨上的新建按钮也一样。Build 的「+」直接打开文件夹选择框（以前那个列出项目的小菜单去掉了，在某个项目里新建用项目行上的按钮）；「项目」标题旁的「+」照旧有新建空白项目、使用现有文件夹和排序。
- Group 的「新建群聊」「新建联系人」在 GRP-04 / GRP-05 之前显示为不可用（`aria-disabled`，悬停提示「即将推出」），点了什么都不做；Group 下的 ⌘N 同样不动。
- 页面入口：「定时任务」「能力」是侧栏底栏的图标（在「设置」右边，明暗切换左边），「Pull Request」只在 Build 模式、且 GitHub 插件启用时出现。当前页的图标用选中底色。不加常驻的左侧图标栏。
- 别的模式有事不会漏：菜单里每种模式旁显示「N 个在运行」和「等你回答」；**只有「等你回答」**（待批准、待回答的问题）会在标的右上角点亮一个小圆点，运行中不打扰。通知铃铛照旧汇总全部。按钮的 `aria-label` 这时加上「，其他模式等你回答」。
- 删除或归档正在看的会话后，打开本模式的下一个会话；本模式没有别的会话了，就进本模式的首页（新草稿），不会跳到别的模式。会话在别处被删、启动时找不到当前会话这类情况，也是先找本模式的，再找最近的；群成员、试用台会话永远不会被选中。
- 窄轨（56px）：标下面三个模式图标（提示写 Chat / Build / Group 和快捷键），当前模式高亮，点了直接切；别的模式有人等你时，那个模式的图标上也有小圆点。窄轨的新建按钮和页面入口同样跟着模式变。
- 搜索查全部模式，结果标出 Chat / Build / Group，当前模式的结果在前；打开结果时自动切模式。群成员会话折算成它所在的群，试用台会话不出现。

## 首页

| 模式  | 问候                                               | 输入框                                                               | 下面                                                   |
| ----- | -------------------------------------------------- | -------------------------------------------------------------------- | ------------------------------------------------------ |
| Chat  | 「{称呼}，今天想聊点什么？」（没有称呼就去掉前缀） | 不提项目                                                             | 5 个常用起手式，点了只填入输入框，不自动发送           |
| Build | 「今天推进哪个项目？」                             | 必须先选项目：没选时项目标签金色高亮、发送按钮禁用；选了之后显示分支 | 最近的 3 个项目 +「打开文件夹…」，也可以把文件夹拖进来 |
| Group | 「今天找谁帮忙？」                                 | 输入 @ 提到联系人                                                    | 联系人、最近的群                                       |

Group 首页的输入框：@ 一位联系人 → 打开和他的单聊并发出这条消息；@ 两位及以上 → 自动建一个临时群（成员是被 @ 的人，Emperor 作为主持人加入），这条消息作为点名消息发进新群。群名取第一句话：去掉 @，截到第一个「。！？.!?」或换行，最长 20 字；取出来是空的就用「临时群 · 成员名」。

首次启动的引导优先于首页。
