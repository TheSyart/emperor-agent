皮肤只改外观：颜色令牌、标题字体和几张 PNG / WebP 装饰图。它不能带脚本，也不能改对话正文、代码、改动对比、权限确认、费用和登录界面的样子。Emperor 自带三套官方皮肤，你也可以照本文做一个皮肤包，在「设置 › 常规 › 外观 › 皮肤」里从文件夹导入。

## 皮肤包

一个文件夹，里面只有 `skin.json` 和它用到的图片：

```text
paper/
├── skin.json
├── hero.webp
└── pet.png
```

`skin.json`：

```json
{
  "schema": 1,
  "id": "paper",
  "name": "宣纸",
  "author": "你的名字",
  "license": "CC BY-NC 4.0",
  "description": "一句话说明这套皮肤",
  "base": "light",
  "tokens": {
    "--surface-canvas": "246 239 225",
    "--text-1": "58 34 24",
    "--brand": "184 50 31",
    "--stroke-2": "rgb(90 50 20 / 0.14)"
  },
  "fonts": { "heading": "songti" },
  "slots": { "hero": "hero.webp" }
}
```

| 字段                | 必填 | 规则                                                                                                                                                    |
| ------------------- | ---- | ------------------------------------------------------------------------------------------------------------------------------------------------------- |
| `schema`            | 是   | 现在只有 `1`                                                                                                                                            |
| `id`                | 是   | 小写字母、数字和连字符，2 到 32 个字符；不能和官方皮肤（`yushufang`、`zhupi`、`richang`）重名。导入后文件夹名就是 id                                    |
| `name`              | 是   | 1 到 40 个字                                                                                                                                            |
| `author`、`license` | 否   | 各不超过 60 个字                                                                                                                                        |
| `description`       | 否   | 不超过 120 个字，显示在皮肤卡片上                                                                                                                       |
| `base`              | 否   | `light` 或 `dark`：皮肤只有这一种明暗，用它时窗口固定显示这一种，切换明暗会提示「只有浅色」；`auto`（默认）：跟随你的明暗设置，令牌在浅色和深色下都生效 |
| `tokens`            | 否   | 要改的颜色令牌，最多 64 个，见下一节                                                                                                                    |
| `fonts`             | 否   | 只有 `heading`（首页问候语等标题）：`system`（默认）、`songti`（宋体）、`kaiti`（楷体）、`rounded`（圆体）。字体由 Emperor 决定，皮肤不能写字体名       |
| `slots`             | 否   | 装饰位 → 同一文件夹里的图片文件名，见「装饰位」                                                                                                         |

其他字段一律拒绝。

## 能改的令牌

只能改 `semantic.light.css` / `semantic.dark.css` 里的这几类语义令牌，名单在运行时从这两个文件读出，不会和界面脱节：

- 表面：`--surface-canvas`、`--surface-base`、`--surface-raised`、`--surface-overlay`、`--surface-sunken`、`--surface-selected`、`--surface-strong`、`--surface-hover`、`--surface-active`、`--surface-hover-strong`、`--surface-hover-solid`
- 文字：`--text-1` 到 `--text-4`、`--text-disabled`、`--text-inverted`、`--text-link`、`--text-accent-muted`、`--text-on-accent`
- 描边：`--stroke-1` 到 `--stroke-4`、`--stroke-inverted`、`--hairline`
- 品牌与强调：`--accent`、`--accent-hover`、`--accent-soft`、`--brand`、`--focus-ring`、`--bubble-user`

不能改：字号、行距、间距、圆角、字体、阴影与遮罩、状态色（`--ok`、`--warn`、`--error`、`--attention`、`--info`：出错必须像出错）、危险操作的悬停色（`--surface-hover-danger`）、「增强对比度」会加深的实线（`--stroke-solid`、`--stroke-solid-strong`），以及组件令牌（`--input-major` 这类，它们跟着上面的语义令牌变）。

取值的写法跟着令牌：

- 实色令牌写三个 0 到 255 的整数，空格分开：`"246 239 225"`；
- 半透明的令牌（`--surface-hover`、`--surface-active`、`--surface-hover-strong`、`--stroke-*`、`--hairline`）写 `rgb()`：`"rgb(90 50 20 / 0.14)"` 或 `"rgb(90 50 20)"`。

不接受十六进制、颜色名、`var()`、`url()` 或别的写法。

### 看得清

`--text-1`、`--text-2` 在 `--surface-canvas`、`--surface-base` 上的对比度都要至少 4.5 : 1（WCAG AA），皮肤自己的文字要满足，基础主题的文字放在皮肤的背景上也要满足（禁区里的正文用基础主题的颜色，背后是皮肤的底色）。`auto` 皮肤在浅色和深色下各查一次。不满足时导入会被拒绝，并写明是哪一对、只有多少，例如：

> 「--text-2」在「--surface-canvas」上的对比度只有 1.5 : 1，至少要 4.5 : 1（浅色）

## 装饰位

| 装饰位          | 位置                                                                                                                          |
| --------------- | ----------------------------------------------------------------------------------------------------------------------------- |
| `hero`          | 空白首页（Chat、Build、Group）问候语上方，高 128 px；和联系人单聊时不显示                                                     |
| `sidebarFooter` | 已弃用（GRP-21）：侧栏不再画人物装饰；第三方皮肤仍可声明这个键，校验照过，只是不显示                                          |
| `approved`      | 你在权限确认卡上点了允许、且这次回答发出去后，输入框右上方盖章似地出现一下（约 1.4 秒），从不盖在确认卡上，也不替换按钮上的字 |

图片都只是装饰：没有替代文字，读屏软件跳过，不能拖动，点不到。设计稿里的 `composerCorner`、`thinking`、`done`、`error`、`groupBackdrop` 还没有开放，写了会被拒绝。

「设置 › 常规 › 外观 › 显示吉祥物」（BRD-04，默认开）关掉后，所有装饰位都不显示（皮肤的颜色和字体不受影响）。皮肤的首页图和 Build 第一次首页的龙椅图在同一个位置，皮肤的图优先，一屏不会出现两个小单。

### 图片

- 只能是 PNG 或 WebP。格式看文件内容的开头，不看扩展名，而且两者必须一致（把 WebP 改名成 `.png` 也会被拒绝）。
- 单张不超过 512 KB，长宽都不超过 2048 px；全部图片合计不超过 4 MB。
- 建议透明背景，按显示高度的两倍准备（`hero` 约 256 px 高）。

## 会被拒绝的包

- 含有 `.js`、`.mjs`、`.cjs`、`.ts`、`.html`、`.htm`、`.svg`、`.css`、`.wasm` 等文件：皮肤不能带脚本、网页、SVG（SVG 里能藏脚本）或样式表；
- 除了 `skin.json` 和 PNG / WebP 以外的任何文件（访达的 `.DS_Store` 会被忽略、不会复制）、子文件夹、链接；
- 超过 16 个文件，或 `skin.json` 超过 64 KB；
- 上面任何一条字段、令牌、对比度或图片的规则不满足。

导入时会列出全部原因，一次改完。

## 不会被装修的地方（禁区）

下面这些地方始终是基础主题的样子，皮肤改了的令牌在这里会被改回基础值（`SkinExempt`，或在根元素上绑定 `useSkinExempt()`），也不会出现装饰图：

- 对话正文，包括其中的代码块、改动对比、花费行（会话流、外部 Agent 的会话、群聊消息流）；
- 工作台里的文件预览与代码、Git 改动对比、回合改动、终端；
- 权限确认卡、电脑操作授权卡、所有确认框；
- 费用：「设置 › 用量与费用」、群聊的本轮花费；
- 登录与凭据：Claude Code 登录、API Key 与连接 Key 的对话框、添加模型时填 Key 的一步、密码管理器、登录状态。

视觉测试会在 朱批 下截一张权限确认卡，和不用皮肤时逐像素比较，必须完全一样。

## 安装、使用与删除

- **导入**：「设置 › 常规 › 外观 › 皮肤 › 从文件夹导入…」，选一个含 `skin.json` 的文件夹。Emperor 检查后把 `skin.json` 和用到的图片复制到 Emperor 数据目录的 `skins/<id>/`（复制完再查一次），之后原文件夹可以移走。已经导入过同一个 id 时会先问是否替换。
- **使用**：在皮肤卡片上点「使用」。选择记在这台 Mac 上（和明暗设置一样）；下次启动先按记住的样子画出来，再请主进程重新检查一遍。
- **删除**：导入的皮肤可以删除，不影响你原来的文件夹；官方皮肤不能删除。正在用的皮肤被删、或者它的文件夹被手动删掉、改坏了，Emperor 会换回「御书房」并提示。

## 实现约定

- 主进程每次读皮肤都重新检查整个包；`app://skin/<id>/<文件名>` 只交出这个皮肤某个装饰位用到、而且仍然通过检查的图片，读取时再核对一次文件头，响应带 `nosniff`，只接受 GET。地址里没有路径，`..`、编码过的斜杠、子目录、别的文件都返回 404。只有主窗口（`app://bundle`）能请求。
- 渲染端的 SkinHost（`skin/skinState.ts`）把令牌写成根元素的内联样式，不加样式表；标题字体是 `--font-heading`（默认等于 `--font-sans`）。禁区要用的基础值由主进程算好：皮肤改的令牌，加上所有直接或间接引用它们的令牌（例如改了 `--surface-base`，浅色下的 `--input-major` 也要还原），按每种明暗分别给出。
- 只有一种明暗的皮肤通过 `useTheme` 的锁固定明暗；你原来的选择保留，换皮肤后恢复。
- 装饰位的样式写在组件里，合计不超过 2 KB；全局样式表只多一个 `--font-heading`。设置页、导入界面和装饰图都按需加载。
- 新加装饰位：在 `SKIN_SLOTS` 里加名字，在界面上放 `<SkinSlot name="…">`（不能放进禁区），更新本文的「装饰位」。新加禁区：在根元素绑定 `useSkinExempt()`，并加进 `skinZones.test.ts` 的名单。
